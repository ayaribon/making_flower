# 🎤 歌ってみた機能 要件定義（KotoBouquet 相乗り）

- 作成：2026-11-09
- 更新：2026-11-10
- ブランチ：`feature/singing-mixer`
- 画面：`/singing`（ログイン必須。既存の編集画面には手を入れない）
- 状態：コード確認ベースの現状整理（未検証項目は課題に残す）

## 1. 目的
**「録音 〜 ミックス 〜 MV制作」を1つの画面の流れで完結させる。**
音楽（オケ）を入れて歌を録り、ミックスして、テンプレートでMVにして保存できる。MVを作らずに音声だけ保存することもできる。

## 2. 全体の流れ
```
① 音楽を入れる → ② 録音 → ③ ミックス → ④ MV制作（テンプレート） → ⑤ 保存
                                    └──────────────→ ⑤ 音声だけ保存
```

## 3. 機能要件

### ① 音楽を入れる
| No | 要件 | 備考 |
|---|---|---|
| F1-1 | オケ（伴奏）の音声ファイルを読み込める | mp3 / wav / m4a など、ブラウザが読める形式 |
| F1-2 | 読み込んだら長さを表示する | 試作で実装済み |

### ② 録音
**歌声は「その場で録音」がメイン。** 録音済みファイルを入れるのもOK（サブ）。

| No | 要件 | 備考 |
|---|---|---|
| F2-1 | **（メイン）** オケを流しながら、その場でマイクで歌を録音できる | オケはヘッドホンで聴く前提（マイクにオケが入らないように） |
| F2-2 | 録り直しができる | |
| F2-3 | （サブ）録音済みの歌声ファイルを読み込むこともできる | 他のアプリで録った声にも対応。試作で実装済み |
| F2-4 | 録音の前にマイクの使用を許可してもらう案内を出す | ブラウザの決まりで、許可がないと録音できない |

### ②' 音のずれ直し（録音・ファイルどちらでも）
| No | 要件 | 備考 |
|---|---|---|
| F2-5 | **録音した声でも、ファイルで入れた声でも、オケとのずれを直せる** | どちらの入れ方でも同じ「ずらし」スライダーを使う |
| F2-6 | 手動で直せる：歌声を前後にずらす（ミリ秒単位、例：±1000ms） | 聴きながら合わせる。ボタンで細かく±10ms も |
| F2-7 | 録音のときは、端末の遅れ（マイクとスピーカーの遅れ）を最初から自動で引いておく | ブラウザが教えてくれる遅れの値を使う。端末によっては正確でないので、残りは F2-6 で直す |
| F2-8 | ずらした結果をすぐ試聴できる | |

### ②'' ずれ直しをもっと自動に（11/09 追加）
ねらい：**手動の ±10ms 調整をほぼ不要にする。** 自動で合わせた結果は、いつでも手動（F2-6）で上書きできる。

| No | 要件 | 備考 |
|---|---|---|
| F2-9 | **遅れの測定（キャリブレーション）**：「📏 遅れを測る」ボタンで、スピーカーから「ピッ」を数回鳴らしてマイクで拾い、端末の本当の遅れを測る | ブラウザが教えてくれる値（F2-7）より正確。測るときだけスピーカーで鳴らす（ヘッドホンだとマイクに届かない） |
| F2-10 | 測った遅れは端末ごとに覚えておき、次から録音するたびに自動で使う | ブラウザの中（localStorage）に保存。サーバーには送らない（N1）。イヤホンを変えたら測り直す案内を出す |
| F2-11 | **カウントインで合わせる**：録音の頭に「1・2・3・4」のクリックを鳴らし、4拍目で手拍子（または「タッ」と声）をしてもらう。その音の位置から、録音ごとのずれを自動で直す | 測定（F2-9）をしていなくても使える。手拍子の部分は書き出しに入らない |
| F2-12 | **ファイルで入れた声も自動で合わせる**：声の中にオケの音（音もれ）や手拍子が入っていれば、オケと比べて一番合う位置を自動で探す | 音もれがない声だと見つからないことがある → そのときは「自動で合わせられませんでした」と出して手動（F2-6） |
| F2-13 | 自動で合わせた結果と、どの方法で合わせたか（測定値／カウントイン／オケと比較）を画面に表示する | うまく合わなかったときに原因が分かるように |
| F2-26 | **おすすめのずれ補正**：「🔍 おすすめを再計算」でオケと声を比べておすすめの値を出し、「✅ おすすめを採用」を押したときだけ入れる（試聴して決められる） | 比べるのはノイズ消し前・録り直し反映後の声。比べられないときは「おすすめなし」（📏の値は録音時に引き済みなので候補にしない）。11/09 ユーザー実装＋修正 |

### ②''' 録音した声のノイズ消し（11/09 追加）
ねらい：**部屋の「サー」「ブーン」や、歌っていない部分の雑音を減らす。** 歌声そのものは傷つけない。

| No | 要件 | 備考 |
|---|---|---|
| F2-14 | 録音の最初に、1〜2秒だけ「静かにしてください」の時間をとり、部屋の雑音を覚える | 覚えた雑音を F2-16 で使う |
| F2-15 | 低い「ブーン」を消す（ローカット：だいたい 80Hz より下を切る） | エアコン・机の振動・マイクに当たる息など |
| F2-16 | 「サー」という一定の雑音を、覚えた雑音をもとに減らす | 録音が終わったあとにまとめて処理する。強さはスライダーで調整（0＝なし） |
| F2-17 | 歌っていない部分の雑音を小さくする（ノイズゲート） | 歌い始め・歌い終わりが切れないように、なめらかに閉じる |
| F2-18 | ノイズ消しの ON／OFF をすぐ聴き比べられる | 消しすぎると声がこもる・ロボットっぽくなるため |
| F2-19 | 録音済みファイルで入れた声にも同じノイズ消しを使える | その場合 F2-14 の代わりに、ファイルの中の静かな部分から雑音を覚える |

※ ブラウザに最初から入っている雑音除去（`noiseSuppression`）は、話し声向けで歌声が途切れたりこもったりするので使わない（手順2で OFF にした）。

### ②'''' 途中から録り直す（パンチイン・11/09 追加）
ねらい：**失敗したところだけ録り直す。** 最初から全部録り直さなくていいようにする。

| No | 要件 | 備考 |
|---|---|---|
| F2-20 | 再生バーで「ここから録り直す」位置を選べる（波形を見ながら） | 今は再生位置を選ぶ画面がないので、波形と再生バーを新しく作る |
| F2-21 | 録り直す少し前（例：2秒前）からオケと今の声を流して、ノリをつかんでから録音に入る | ヘッドホンの音がマイクに入る場合に備え、「録り直し中は今の声を鳴らさない」設定も付ける |
| F2-22 | 録り直した部分だけ元の声と差し替える。つなぎ目はなめらかにする（0.02秒くらい重ねて切り替え） | 「プツッ」と鳴らないように |
| F2-23 | 録り直しの終わりは「⏹を押したところまで」か「終わりの位置を先に決める」のどちらか | |
| F2-24 | 差し替える前の声に戻せる（1つ前に戻す） | 声は「元の声＋差し替えた部分のリスト」で持つ |
| F2-25 | 録り直した部分にも同じずれ直しとノイズ消しをかける | 途中ではカウントインが使えないので、最初の録音で測った遅れ（手拍子か📏の値）を使う。雑音も最初の録音で覚えたものを使う |

### ③ ミックス
| No | 要件 | 備考 |
|---|---|---|
| F3-1 | オケと歌声の音量バランスを変えられる | 試作で実装済み |
| F3-2 | （ずれ直しは ②' に移動） | |
| F3-3 | 歌声を整えてくれる：リバーブ（響き）、コンプレッサー（声量をならす）、EQ（こもりを取る） | 「ミックスしてくれて」＝**おすすめ設定を最初から入れておき、スライダーで微調整**できる形にする |
| F3-4 | 試聴できる | 試作で実装済み |

### ④ MV制作（テンプレート）

> **作り方の提案（11/09・まだ決めていない）**
> - **全部ブラウザの中で作る（N1）**。動画の1コマを「曲の t 秒目の絵」として描く関数（`renderFrame(t)`）を1つ作り、プレビュー・今の録画方式・将来の速い書き出し（WebCodecs）で同じものを使う
> - **おまかせで動く**：ミックスで決めた「部分（サビなど）」でエフェクトが変わる（サビで明るく・ズーム・色が変わる）。オケの拍（音の立ち上がり）に合わせて波形や背景がはねる。背景画像の色から、文字や波形の色を自動で決める
> - **テンプレート（Q3 の案）**：①シンプル（背景＋波形＋曲名）②歌詞テロップ（カラオケ風）③ジャケット（真ん中に画像、ゆっくりズーム）④ビジュアライザー（周波数のバー）
> - **向き**：横 16:9（YouTube）・縦 9:16（TikTok・ショート）・正方形 1:1。KotoBouquet の背景素材（`public/backgrounds` の -9x16 / -1x1）と、マイ画像（`user_images`）がそのまま使える
> - **歌詞**：貼り付けた歌詞を、曲を流しながら1行ずつタップして時間を合わせる（自動の聞き取りはサーバーや AI が要るので後回し）
> - **クレジット**：最初に曲名・歌った人、最後にオケのクレジットを自動で出す（F4-4）
> - **進め方**：4a テンプレ＋背景＋曲名＋プレビュー → 4b 歌詞のタップ合わせ → 4c サビ・拍で動くおまかせ演出 → 4d 縦・正方形 → 4e 速い書き出し（Chrome の WebCodecs。iPhone は今の録画方式）
| No | 要件 | 備考 |
|---|---|---|
| F4-1 | ミックスした音のまま、動画編集に進める | |
| F4-2 | 動画はテンプレートから選ぶだけで作れる（自由な編集はしない） | 例：背景画像＋波形、背景画像＋歌詞テロップ |
| F4-3 | 背景画像を選べる：手元の画像／マイ画像（KotoBouquetで作った画像） | 既存の `user_images` を使う |
| F4-4 | 曲名・歌った人の名前・クレジットを入れられる | オケのクレジット表記用 |
| F4-5 | 歌詞テロップ（任意） | |
| F4-6 | 書き出す前にプレビューできる | |

### ⑤ 保存
| No | 要件 | 備考 |
|---|---|---|
| F5-1 | MVを動画ファイルで保存できる | Chrome/Edge は WebM、iPhone は MP4 の見込み |
| F5-2 | **MVを作らずに、ミックスした音声だけ保存できる** | WAV で実装済み（手順2）。曲の長さぶん待たずにすぐできる |
| F5-3 | 保存先は自分の端末（ダウンロード） | サーバーには保存しない |

## 4. 守ること（非機能要件）
| No | 要件 | 理由 |
|---|---|---|
| N1 | オケ・歌声・動画はブラウザの中だけで扱う（サーバーに送らない） | ファイルが重い、S3の費用、権利物を預からないため |
| N2 | DBの追加は最初はしない | 混ぜ具合の保存などは必要になってから |
| N3 | PC（Chrome/Edge）とスマホ（iPhone Safari）で使える | |
| N4 | 既存の編集画面に影響を出さない | 新しいページで作る |
| N5 | 画面にオケの権利についての注意を出す | 配布元の規約確認をうながす |
