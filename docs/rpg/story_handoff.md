# 📖 ストーリー 引きつぎ資料（別の セッション へ）

KotoBouquet（making_flower）の ゲーム部分の **全体の ストーリー** を 考えて ほしい。
2026-11-19 に ayaribon が「全体の ストーリーを 決めないと いけないので、別の セッションに 任せる」と 決めた。この 資料だけで 考えられる ように、いま ある もの と 決まって いる ことを まとめた。
ストーリーが できたら ayaribon が 確認して、Claude が ゲームに 組みこむ。

---

## 1. このアプリ と ゲーム
- **SiVA** という 事務所の みんな（スタッフ・タレント）が 使う、内輪の アプリ。歌ってみた・サムネ作り・切り抜き依頼 などの 道具が あり、そこへ ゲームの 要素を 足している
- 遊ぶ 人は 事務所の 人。**内輪ネタ・ゆるい 笑い** が 合う（例：Dettyan 本人が 遊ぶと「…って、あんない してるの 俺やん！」）
- 画面の ことばは **短く やさしい 日本語**。いまの ゲームは「ひらがな 多め・ことばの あいだに すきま」の 書き方（下の 例 を 参照）
- 絵は Sprout Lands（Cup Nooble）の ドット絵の 絵柄（やわらかい 色・ちいさな 町・草原）

## 3. いま ある おはなし（第1章 はじまりのまち）
育成ゲーム（Dettyan が 主人公）の おはなし。`app/javascript/dettyan_story.js`。

**あらすじ**：いつものように 配信していた Dettyan が、画面の ひかりに つつまれて 異世界『はじまりのまち』に とばされる。家も お金も ないので まちはずれに テントを はって 野宿。スライムを たおして お金を ため、マイホーム を 買い、つくえ・いす・パソコン を そろえて 配信できる ように なる。「…でも ここ 異世界やん。だれが 見てくれるんやろ？」で 第1章 おしまい。

**目標（画面の 上に 出る）**
1. 🗺️ ぼうけん に 出て、スライムを たおそう（※ ぼうけん は「しゅぎょう」に 名前が かわる 予定）
2. 🏠 お金を ためて マイホーム を 買おう（💰3000）
3. 💻 つくえ・いす・パソコン を そろえよう
- ほかに、Lv5 で ジョブチェンジ の おはなし（せんし・まほうつかい・うたうたい）

**おはなしの 本文（そのまま）**
```
prologue（はじまり）
  [もとの世界の へや・うしろすがた] いつものように 配信していた、ある夜のこと。
  [〃] Dettyan「みんな ありがとう〜！ じゃあ つぎの 曲 いきます！」
  [ひかる画面] そのとき、画面が まぶしく ひかりだして……
  [はじまりのまち] ……きがつくと、見たこともない まち に たっていた。
  [〃] Dettyan「え、ここ どこ？」　かんばんには『はじまりのまち』と かいてある。
  [テント] 家も お金も ない。しかたなく、まちはずれに テントを はった。
  [〃] スライムを たおして お金を ためて、マイホーム を 手に入れよう！

  [はじまりのまち] はじまりのまち の しんでん から、ふしぎな 声が きこえた…

  [へや] ついに マイホーム を 手に入れた！

pc（パソコン）
  [へや・うしろすがた] パソコン が ついた！ これで へんしゅう も 配信も できる。
  [へや] Dettyan「…でも ここ 異世界やん。だれが 見てくれるんやろ？」
  [〃] 📖 第1章 おしまい。つづきは じゅんび中……
```

## 5. 決まって いる ゲームの しくみ（ストーリーを 合わせて ほしい ところ）
- **2つの ゲームが ある**
  1. **育成ゲーム**（`/dettyan`）：みんなが それぞれ **Dettyan を 育てる**。しゅぎょう（いまの「ぼうけん」）で 強く なる。第1章 は ここ
  2. **RPG**（これから）：**自分の キャラ が 主人公**。**育てた Dettyan が ペット（なかま）として ついて きて いっしょに たたかう**。町の 門から 外へ 出て エリアを すすむ
- **⚠️ つじつまを 合わせて ほしい 点**：第1章 では「Dettyan 本人が 異世界に とばされた」。RPG では「プレイヤーが 主人公で、Dettyan が ペット」。この 2つが 1つの 話として つながる ように して ほしい（例：プレイヤーも Dettyan を 追って この 世界に 来た？ 配信を 見ていた 人たち が 来た？ など。決め方は おまかせ）
- レベル：**MAX 99**（いったん）。Lv10 までは 1日、Lv30 くらいから きびしく なる（Lv30→35 は 1日2時間 で 1か月）。章や ボスの 目やす レベルは この ペースに 合わせて
- 職業：せんし・まほうつかい・うたうたい（Lv5 で ジョブチェンジ）
- そうび：あたま・いしょう・て（ぶき・マイク・ペンライト など）・せなか・くつ。歌・配信 ネタの ものが 多い（マイク・金のマイク・ステージいしょう・ペンライト・ハートのうちわ）
- やられたら 町に もどる

## 6. 考えて ほしい こと（とどけて ほしい もの）
1. **全体の あらすじ**（はじまり → 終わり。エンディング まで）。何章 くらいか
2. **章の 表**：章ごとに 題名・舞台（エリア）・目やす レベル・目標（2〜4こ）・ボス
3. **各章の おはなしの 本文**：上の 3 と 同じ 形（場面ごと：背景・だれが 話すか・ことば）。1場面 1〜2行、1つの おはなし 3〜8場面
4. **ボス**：名前・どこに いるか・どんな 見た目か（あとで 絵を たのむ ので、色・形・大きさ を ことばで）・大わざ の 名前
5. **新しい 登場人物・場所** が あれば、その 説明（見た目・話し方）
6. 第1章（育成ゲーム）と RPG の つながり方（5 の ⚠️）
7. （あれば）サブの おはなし・町の 人の セリフ・称号 など

**わたし方**：この 形の markdown 1つ（`story.md`）。ゲームへの 組みこみ（目標の 判定・場面の 絵）は Claude が やる。新しい 背景の 絵が いる 場面は「背景：〇〇（新しい 絵が いる）」と 書いて おいて ほしい。

## 7. 気を つける こと
- 内輪の アプリ なので、実在の 人を いやな 気持ちに させる ネタ は なし。事務所の 実在の タレントを 出すか は ayaribon に 聞く（いまは Dettyan だけ）
- こわすぎ・グロ は なし（だれでも 遊べる ゆるさ）
- 絵は Sprout Lands の 絵柄。現代的な もの（パソコン・配信・マイク）が 出ても よい（いまも 出ている）
- 参考：`docs/dettyan/requirements.md`（育成ゲーム）、`docs/rpg/requirements.md`（RPG の 要件）、`docs/town/requirements.md`（町）
