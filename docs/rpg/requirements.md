## 1. やりたいこと（ayaribon の ことば）
1. **町の 外へ 出て ぼうけん**：「メインメニューの マップを 移動したら 外に 出る、みたいな のが あって、そこから 冒険 行ける」

## 2. いまの しくみ（たたき台を 考える ための 材料）

### 2.1 だれが たたかう か
| | 町（`/`） | 育成ゲーム（`/dettyan`） |
|---|---|---|
| 主人公 | **自分の キャラ**（キャラメイク） | **Dettyan**（みんなが それぞれ 育てる） |
| 強さ | ない | レベル・職業・ステータス・そうび |
| 保存 | `users.avatar`（見た目だけ） | `dettyan_saves.data`（JSON。1人 1つ） |

→ 町の 外で たたかう のは **自分の キャラ（主人公）**。Dettyan は ペット（なかま）として いっしょに たたかう（Q1。2026-11-19 に ayaribon が 決定）。

### 2.2 レベル（③ の 材料。いまの 数字）
- つぎの レベルまで の 経験値：`10 + (レベル − 1) × 8`（`dettyan_battle.js` の `expToNext`）。上がり方が まっすぐ（だんだん きつく ならない）
- そこまでの 合計：Lv2＝10、Lv5＝88、Lv10＝378、Lv20＝1558
- 1回の ぼうけん で もらえる 経験値（だいたい）：公園 10、森 20、どうくつ 50、山 70
- 行ける 場所：公園 Lv1・森 Lv3・どうくつ Lv6・山 Lv10。**山（Lv10）の 先が ない**ので、Lv10 を こえると やる ことが へる
- げんき：公園 15・森 25・どうくつ 40・山 60（さいだい 100 くらい。時間で もどる）
- → 1日に 数回 ぼうけん すると、**数日で Lv10**（山）に とどく。「すぐ 上がりすぎる」は、**数字より 行き先・目標が すくない こと** が 大きい と 思う

### ③ レベルの つりあい
**目やす（Q9 で 決定。2026-11-19）**：Lv10 までは 1日で いける。Lv30 くらいから 経験値かせぎ が いる。Lv30→35 は 1日2時間 遊んで 1か月 くらい。

**たたき台の 曲線**（1つ レベルを 上げるのに かかる 遊ぶ 時間。経験値の 数は、この 時間 × その エリアで 1分に もらえる 経験値 で きめる）
| レベル | 1つ 上げる 時間 | そこまで の 合計 | 1日2時間 なら |
|---|---|---|---|
| 1〜10 | 6分 | 0.9時間 | 半日 |
| 15 | 8分 | 1.4時間 | 1日 |
| 20 | 17分 | 2.3時間 | 1日 |
| 25 | 76分 | 4.9時間 | 2.5日 |
| 30 | 12時間 | 22.6時間 | 11日 |
| 35 | 13時間 | 85時間 | 42日（30→35 で 31日） |
| 50 | 17時間 | 308時間 | 5か月 |
| 99 | 29時間 | 1414時間 | 2年 |
| 999 | 125時間 | 12万時間 | とどかない |

- 式：Lv10 まで 6分。Lv10〜30 は だんだん きつく（6分 → 12時間）。Lv30 から は 12時間 に 1レベルごと 2% ずつ たす
- **MAX は いったん Lv99**（Q19 で 決定。99 より 先 は 要検討）

| 番号 | 要件 | メモ |
|---|---|---|
| F16 | レベルの 上がり方を **だんだん きつく** する（例：つぎまで の 経験値を 2じょう に ちかい 形に） | 数字は 表で ためして きめる（Q9） |
| F17 | **行き先・目標を ふやす**（Lv10 の 先：第2章 の エリア・ボス）。上がりすぎ より「やる ことが なくなる」を ふせぐ | 第2章 の おはなし と いっしょに |
| F18 | **ペット（育成ゲームの Dettyan）の レベル は 上の 曲線に そろえる**（Q10 で「999 を MAX と 見て」→ Q19 で いったん 99 に）。いま 遊んでいる 人は、もっている 経験値の 合計 から 新しい 表で レベルを 計算しなおす（いま の 人は ほとんど Lv10 前後 なので、下がっても すこし）。主人公（自分の キャラ）は まだ レベルが ないので 新しく 0 から | 下がる 人には おしらせ を 1回 出す |
| F19 | つりあい の テスト（いまの `dettyan_battle_test.mjs` の「公園は Lv1 で だいたい 勝てる」など）を 新しい 数字で 書きなおす | |

## 4. 守ること（N〜）
- **N2：DB（テーブル）を ふやさない**。ぼうけんの すすみ・ペット の 状態 は いまの `dettyan_saves.data`（JSON）に 入れる（自分の キャラで たたかう 場合も、まず ここに 入れる 形で 考える）
- **N3：PC と iPhone Safari の 両方**。フィールドは スマホ縦 でも 歩ける（画面いっぱい・カメラが ついてくる。町と 同じ しくみ）
- **N4：いまの 画面を こわさない**。町・育成ゲーム・キャラメイク は いまの まま 使える
- 絵は **Sprout Lands の 絵柄**（町と 同じ）。素材は 公開リポジトリに 入れない（S3）。ドット絵の きまり は `docs/pixel_art.md`
- 絵は 時間 と 場所 で きまる（町と 同じ。セーブ の 同じ 場面は 同じ 絵）

## 5. すすめ方（案）
1. **この 表を きめる**（Q を ayaribon が きめる）
2. **③ レベル**：数字の 表を 作って テストで ためす（いまの ゲーム だけで できる。小さく はじめられる）
3. **② ペット**：町で Dettyan が ついて歩く（見た目 と ひとこと だけ。たたかい は まだ）
4. **④ 主人公の 強さ**：主人公の レベル・ステータス・もっている そうび を セーブに 足す。キャラメイクに 強さ を 出す
5. **① ⑤ フィールド**：門 → 草原 1エリア → 敵を その場で たたく（主人公＋ペット）→ 町へ もどる、を まず 1本 通す
6. ⑥ バッグ・そざいが おちる（モンスターの 個性の 表 と いっしょに）
7. エリア を ふやす・ぶきや・そうび を ふやす・第2章
8. そざいの 使い道：かじや で 作る（F27・F37）・売る
