2026-11-19 に ayaribon が「別の ブランチで やりたい。けっこう 大がかり」と 言った 3つ を、要件の 表に した もの。
まだ **たたき台**。「6. 決めてほしいこと（Q〜）」が きまってから 設計・作業リストに 分ける（作業リストは Kiro が `.kiro/specs/` に 分けても よい）。

- いまの 町：`/`（`docs/town/requirements.md`）。自分の キャラで 歩いて 建物に 入る
- いまの 育成ゲーム：`/dettyan`（`docs/dettyan/requirements.md`）。Dettyan を 育てる。ぼうけん は メニューから えらぶ
- ブランチ：`claude/rpg-adventure`（`claude/game-ui-deploy-improvements-amffjp` から 切った）

## 1. やりたいこと（ayaribon の ことば）
1. **町の 外へ 出て ぼうけん**：「メインメニューの マップを 移動したら 外に 出る、みたいな のが あって、そこから 冒険 行ける」
2. **Dettyan を ペットに**：「育成ゲームは そのままに、育成した でっちゃんを ペット として 連れ回せる」
3. **レベルの つりあい**：「ゲームっぽく するなら レベルの 設定を 考えないと。いまは レベルが すぐ 上がりすぎる？」

## 2. いまの しくみ（たたき台を 考える ための 材料）

### 2.1 だれが たたかう か
| | 町（`/`） | 育成ゲーム（`/dettyan`） |
|---|---|---|
| 主人公 | **自分の キャラ**（キャラメイク） | **Dettyan**（みんなが それぞれ 育てる） |
| 強さ | ない | レベル・職業・ステータス・そうび |
| 保存 | `users.avatar`（見た目だけ） | `dettyan_saves.data`（JSON。1人 1つ） |

→ 町の 外で たたかう のは **自分の キャラ（主人公）**。Dettyan は ペット（なかま）として いっしょに たたかう（Q1。2026-11-19 に ayaribon が 決定）。

### 2.2 レベル（③ の 材料。いまの 数字）
- つぎの レベルまで の 経験値：`10 + (レベル − 1) × 8`（`dettyan_battle.js` の `expToNext`）。上がり方が まっすぐ（だんだん きつく ならない）
- そこまでの 合計：Lv2＝10、Lv5＝88、Lv10＝378、Lv20＝1558
- 1回の ぼうけん で もらえる 経験値（だいたい）：公園 10、森 20、どうくつ 50、山 70
- 行ける 場所：公園 Lv1・森 Lv3・どうくつ Lv6・山 Lv10。**山（Lv10）の 先が ない**ので、Lv10 を こえると やる ことが へる
- げんき：公園 15・森 25・どうくつ 40・山 60（さいだい 100 くらい。時間で もどる）
- → 1日に 数回 ぼうけん すると、**数日で Lv10**（山）に とどく。「すぐ 上がりすぎる」は、**数字より 行き先・目標が すくない こと** が 大きい と 思う

## 4. 守ること（N〜）
- **N2：DB（テーブル）を ふやさない**。ぼうけんの すすみ・ペット の 状態 は いまの `dettyan_saves.data`（JSON）に 入れる（自分の キャラで たたかう 場合も、まず ここに 入れる 形で 考える）
- **N3：PC と iPhone Safari の 両方**。フィールドは スマホ縦 でも 歩ける（画面いっぱい・カメラが ついてくる。町と 同じ しくみ）
- **N4：いまの 画面を こわさない**。町・育成ゲーム・キャラメイク は いまの まま 使える
- 絵は **Sprout Lands の 絵柄**（町と 同じ）。素材は 公開リポジトリに 入れない（S3）。ドット絵の きまり は `docs/pixel_art.md`
- 絵は 時間 と 場所 で きまる（町と 同じ。セーブ の 同じ 場面は 同じ 絵）

## 5. すすめ方（案）
1. **この 表を きめる**（Q を ayaribon が きめる）
2. **③ レベル**：数字の 表を 作って テストで ためす（いまの ゲーム だけで できる。小さく はじめられる）
3. **② ペット**：町で Dettyan が ついて歩く（見た目 と ひとこと だけ。たたかい は まだ）
4. **④ 主人公の 強さ**：主人公の レベル・ステータス・そうび を セーブに 足す（画面は キャラメイク か 新しい「つよさ」画面）
5. **① フィールド**：門 → 草原 1エリア → 主人公＋ペット の バトル → 町へ もどる、を まず 1本 通す
6. エリア を ふやす・そうび を ふやす・第2章
