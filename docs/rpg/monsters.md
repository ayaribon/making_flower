# 👾 モンスターの 個性 と おとす そざい（たたき台）

`docs/rpg/requirements.md` の ⑥（F35・F36）と Q20。**Claude の たたき台**。ayaribon が 直して きめる。
強さの 数字（HP・こうげき など）は いまの `app/javascript/dettyan_battle.js` の `MONSTERS`。フィールドで その場で たたかう（⑤）ときの うごき を 足した。
ストーリーの セッション（`docs/rpg/story_handoff.md`）で ボス・新しい モンスターが 決まったら、この 表に 足す。

## 1. 見かた
- **うごき**：フィールドで どう 動くか（⑤ の アクション）
- **こうげき**：ふつうの こうげき と 大わざ（大わざ は いまの `special`）
- **よわい**：その わざ・まほう が よく きく（せんし＝ぶつり、まほうつかい＝ほのお・こおり・かみなり、うたうたい＝うた）
- **そざい**：たおすと おとす もの。％は おちる わりあい（めずらしい もの は ★）。お金・経験値 は いまと 同じ
- **使い道**：かじや で そうびを 作る（F27）・お店で 売る（Q21 で きまった 2つ）

## 3. そざいの 使い道（たたき台）
| そざい | 作れる もの（かじや） | 売る（めやす） |
|---|---|---|
| ゼリー（みどり・あお・むらさき・あか） | 回復の くすり・スライムの ぼうし（見た目） | 5〜20 |
| くろい はね・コウモリの はね | はねの かざり・マント | 15〜30 |
| きのこの かさ・はちみつ | 料理（育成ゲームの ごはん・しょうらい） | 10〜25 |
| いわの かけら・こうせき・ひかる こうせき | ぶき・たて・ヘルメット | 20〜120 |
| しろい けがわ・こおりの かけら | あたたかい いしょう・こおりの ぶき | 40〜80 |
| りゅうの うろこ・りゅうの きば | いちばん 強い そうび | 100〜300 |
| クモの いと・じょうぶな いと・きんの いと | いしょう（ぬう） | 15〜200 |
| ふしぎな ぬの・おばけの ランタン | まほうの いしょう・ランプ | 50〜250 |
| ★めずらしい もの | とくべつな そうび（1つだけ） | 高い |
