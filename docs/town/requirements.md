# 🏘️ はじまりのまち（トップページの世界）と 👤 アバター 要件

ログインしたあとのトップページを、カードのメニューから **自分のアバターで歩く「町」** にする。建物に入ると、歌ってみた・サムネ・Dettyan・切り抜き の画面へ。2026-11-18 に ayaribon が「一旦 実装してみて」（サマーウォーズの OZ のような世界、ただし見た目は このアプリの ドット絵）。

## 1. まち（`/`）
- 町の名前は **はじまりのまち**（Dettyan 育成ゲームの おはなし と同じ町）。絵は `app/javascript/town_world.js`。
- **町は 横に 長い（256×120 ドット）**（2026-11-18 に ayaribon が「世界を 広く」）。建物の あいだ に ひろば・けいじばん・木・ベンチ・花だん。
  - **画面いっぱい**（2026-11-19 に ayaribon が「MAP 画面を 画面いっぱいに」）：画面の 横長さ に あわせて 見せる はば（120〜256 ドット）を きめ、町を 画面に ぴったり おさめる。たて長の スマホで あまる 上下は 緑。
  - **🔍 拡大・縮小**（2026-11-19 に ayaribon）：右の ＋ − 、スマホは 2本指で ひろげる・つまむ、PC は ホイール。ふつうの 2.5倍 まで 大きく、町の はば（または 森の はし）まで 小さく。大きく すると カメラは 自分の キャラに ついて たて・よこ に 動く。えらんだ 大きさは この 端末の localStorage（`town:zoom`）。ページ ごとの 拡大は しない
  - **🌳 町の 上下の 森**（2026-11-19 に ayaribon が「たて画面の すきまは 木を 生い茂らせて うめて」）：たて長の 画面や 小さく したとき、町の 上と 下に 森（それぞれ 64 ドットまで。Sprout Lands の 木・しげみ・花。種を 固定して 毎回 同じ 絵）。すきまは できない。夜は 森も くらく なる
  - 名前・あいさつ・ボタン（「👕 きがえる」（キャラを つくる前は「👤 キャラを つくる」。2026-11-19 に ayaribon が「キャラを かえる」から 名前を かえた）・❓ あんない・📋 かんたんメニュー・☰ 管理画面／クレジット／ログアウト）は 町の 上に、💬 ひとこと は 町の 下に 重ねる。よこ向きの スマホでは 小さく する。
  - 町が 画面より 広いときは、**自分の キャラに ついて 横に 動く**。見えていない がわ に 町が つづくときは ◀ ▶（押すと そっちへ 歩く）。建物の ボタン も 町と いっしょに 動く。
- 建物は4つ。タップすると、自分のアバターが 入口まで歩いて 入る（入ると、下のカードを押したのと同じ動き＝SiVA の画像を出して移動）。
  - 歩いている とちゅうに **同じ 建物を もう1回 おすと、歩くのを またずに すぐ 入る**（2026-11-19 に ayaribon が「ゆっくりで いやな 人も いる」）。
  - **👁 みわたす**（2026-11-19 に ayaribon が「移動しなくても 見わたせる ように。入りたい 部屋に 入りやすく」）：右の ＋ − の 上の 👁 で 町 ぜんぶ（はば 256）を 1画面に。みわたし中は 建物を タップすると 歩かずに すぐ 入る。もう1回 👁 か ＋ −・ピンチ で もとに もどる

| 建物 | 行き先 | 名前の下の 説明（2026-11-18 に ayaribon が「何が できる場所か 軽い説明書きが ほしい」） |
|---|---|---|
| 🎤 スタジオ | 歌ってみた（`/singing`） | 歌ってみたを つくる |
| 🎨 アトリエ | サムネ・背景（`/editor`） | サムネ・背景を つくる |
| 🏢 Dettyan の 事務所 | Dettyan 育成ゲーム（`/dettyan`） | Dettyan を そだてる |
| ✂️ 編集室 | 切り抜き依頼（`/clip_requests/new`） | 切り抜きを たのむ |

- 説明の もう少し 長い文は、PC では カーソルを のせると 出る（`title`）。画面読み上げ には 名前・説明・長い文 を まとめて 読ませる（`aria-label`）。文言は `app/views/homes/show.html.erb`。

- 地面をタップすると、そこへ歩く（ふんすいの中には入らない）。
- **ほかの人**：**キャラを つくった人だけ** 出る（2026-11-18 に ayaribon が「キャラは 作られたら 足すので いい」。前は キャラの ない人も おまかせの 見た目で 出していたが やめた）。20人まで、さいきん つくった・かえた じゅん。
  - キャラの ない テスト用の アカウント（dettyantest など）も、これで 出ない。
  - Dettyan 本人の アカウントは、キャラを つくるまでは 出ない（町の Dettyan が かわり）。
  - タップすると 名前と ひとこと（ひとこと が なければ あいさつ）。リアルタイムの 同時接続では ない（ページを開いたときの 一覧）。
- **💬 ひとこと**（2026-11-18 に ayaribon が「自分の アバター用に メッセージを かえられるように」）：町の下の「💬 ひとこと」に 書いて「かえる」。20文字まで。
  - 自分の キャラが ふきだしで 言う（開いて すぐ 1回、そのあとは ときどき）。ほかの人の 町でも、その人が 開いたときに 見える。
  - ふきだしは 見えている人の 中から 1人ずつ（3.5〜6.5 秒ごと）。町の はし では はみ出さないように よせる。
  - キャラメイク（`/avatar`）でも かえられる。から に すると けす。キャラを まだ つくっていない人には 入力を 出さない。
- **📖 あんない（チュートリアル）**（2026-11-18 に ayaribon が「初回に『SiVA へ ようこそ！』からの チュートリアル」）：はじめて 町を 開いたとき に 出る。
  1. 「SiVA へ ようこそ！」（SiVA の アイコン）→ 2. Dettyan が あいさつ（本人なら「…って、あんない してるの 俺やん！」）→ 3〜6. 建物を 1つずつ（その建物が 光る。スマホは カメラが そっちへ 動く）→ 7. あるきかた → 8. 💬 ひとこと（キャラが ある人。「下の『💬 ひとこと』に 書くと、まちの みんなに ひとこと のこせるよ。」）→ さいご（キャラが ない人には「👤 キャラを つくる」）。
  - 「とばす」で いつでも おわれる。とばした まだ キャラが ない人には「まずは キャラを つくろう」。
  - 見たかどうかは **この端末の localStorage だけ**（`town:guide:v1:呼び名`。DB は 使わない）。ちがう 端末では もう一度 出る。おぼえられない 端末では 出さない（町の下の「❓ あんない」で いつでも 見られる）。
  - 中身を 大きく かえたら `GUIDE_KEY` を v2 に して、みんなに もう一度 見せる。
  - あんない の あいだは、町を タップしても 歩かない・建物に 入らない。
- **Dettyan** が 事務所の前の ひろば に立っている（2026-11-19 に ayaribon が 仕様を かえた）。
  - 見た目は **Dettyan 本人の アカウント**（呼び名 `dettyan`。`DETTYAN_OWNER_NAMES`）が キャラメイク で つくった キャラ。まだ つくって いなければ いつもの 見た目（黒髪マンバン・いつもの服・まゆげ）。名前は 本人の 表示名。
  - タップすると 案内の ことば（「ようこそ、はじまりのまち へ！」など）→ そのあと 本人の ひとこと（書いて いれば）。
  - 本人は「ほかの人」には 出さない（2人に ならない）。
  - **本人が ログインして 見ているとき** は ひろばには 出さない（歩いている 自分が Dettyan）。あんない の Dettyan の ばめん は 自分を うつす（「…って、あんない してるの 俺やん！」）。
  - 育成ゲームの Dettyan は べつ（いつもの 見た目 に そうびを 重ねる。docs/dettyan/requirements.md）。
- 空は 日本の時間で 朝・昼・夕方・夜（夜は まどと 街灯に あかり）。ふんすいの 水しぶき・くも が動く。
- まだ キャラを つくっていない人には「まずは じぶんの キャラを つくろう！」（あとで も えらべる）。
- **📋 かんたんメニュー**（2026-11-19 に ayaribon が「演出が いらない 人も いる。かんたんメニューに 移れて、もどれて、その設定は 固定」）：町の 右上の「📋 かんたんメニュー」で カードだけの 画面（`homes/simple`）に。「🏘️ まちの 画面に もどる」で もどる。
  - えらんだ ほうは **この ブラウザの cookie**（`home_mode`。ずっと のこる）に おぼえて、次に `/` を 開いても その画面。DB は 使わない（N2）。ちがう 端末では はじめは 町。
  - 町の 画面にも カードは 見えない形で のこす（`data-town-place`。建物に 入ると そのカードを 押したのと 同じ 動き）。
- 動きを減らす設定の人には、ほかの人は うろうろしない。

## 2. キャラメイク（`/avatar`）
- 町の上の「👤 キャラを つくる／かえる」から。左に 大きく 見本（まばたき・ときどき 足ぶみ）、右で えらぶ。🎲 おまかせ・↩ もとにもどす・💾 これにする（保存して 町へ もどる）。
- **絵は 16×20 ドットの 2頭身**（`app/javascript/avatar_chibi.js`。2026-11-18 に Sprout Lands の 町に あわせて 描き直した。ayaribon が「町と 同じくらいの 細かさ」）。頭は 大きく まるく、目は 小さい 点。色は パステル寄り。ふちは 黒ではなく となりの 色を こくした 色（自動）、右と 下に うすい かげ。こもの も 描き直した（Dettyan の そうびの 絵は もう 使わない）。
  - 前の 20×24 の 絵（`avatar_sprite.js` の `drawAvatar`）は 画面では 使っていない。データの 形（normalizeAvatar）・パーツの 表 は `avatar_sprite.js` の まま。色の 番号も 同じ なので、保存した キャラは そのまま 新しい 絵に なる。
  - 32×40 の もっと 細かい 見本も 作ったが、町と 細かさが ちがうので やめた。
- えらべるもの（表は `app/javascript/avatar_sprite.js`。1つ足せば ふえる。id は保存されるので あとから変えない。絵は `avatar_chibi.js` にも 足す）：

## 2.5 🏷️ 表示名（2026-11-18 に ayaribon が「表示名を みんな それぞれ かえられるように」）
- キャラメイク（`/avatar`）の「🏷️ なまえ（まちに 出る）」で かえる。12文字まで（見えない文字は すきまに）。空に すると ログインの 呼び名に もどる。
- 出る ところ：まちの 自分・ほかの人の なまえと ふきだし、トップの「〇〇 さん、うぇるかむ」、キャラメイクの 見本の 下、管理画面の ユーザー一覧（呼び名の 横に かっこ書き）。
- **ログインの 呼び名（`name`）は かえない**（ログインID の 頭に 入る・Dettyan 本人の 見分けに 使う）。あんない を 見たか の しるし も 呼び名の まま。
- 編集画面（`/editor`）の メニューは 呼び名の まま（N4：編集画面は さわらない）。

## 3. 保存（DB）
- `users` テーブルに **`avatar` の列**（text。中身は JSON。`User` の `serialize`）と **`display_name` の列**（string 40。表示名）を 足した。**テーブルは 増やしていない**。
  - AGENTS.md の N2（DB を増やさない。必要なら Issue で相談）に かかる。**マージの前に ayaribon が OK するか 決める**（まだ）。
  - マイグレーション：`db/migrate/20261120090000_add_avatar_to_users.rb`・`20261121090000_add_display_name_to_users.rb`（本番は Procfile で デプロイのときに 自動で流れる）。
- `PATCH /avatar`（JSON：`{ avatar: { hair: "bob", ... } }`）。サーバーは 知らない項目・へんな値（数は 0〜99、文字は 英小文字だけ）を すてる（`User.clean_avatar`）。何も のこらなければ 保存しない。
  - **送った 項目だけ かわる**（いまの 中身に かさねる）。町の 💬 は `{ avatar: { msg: "..." } }` だけ 送る。`msg: ""` で けす。
  - 💬 ひとこと は 同じ JSON の `msg`（**列は 増やしていない**）。改行・タブ・見えない文字（ゼロはば・向きを かえる 文字）は すきまに して、20文字まで（絵文字も 1文字）。画面の `cleanMsg`（`avatar_sprite.js`）と 同じ きまり。画面には `textContent` で 出す（HTML に ならない）。
- 画面は どんな データでも `normalizeAvatar` で いつも 使える形に そろえて 描く。

## 4. 守ること
- N1：音・動画は あつかわない。
- N3：PC とスマホ。建物は ボタン（キーボード・画面読み上げでも 押せる）。カードのメニューも のこす。
- N4：編集画面・歌ってみた の 中は さわらない（入口が かわるだけ）。
- ほかの人に 見えるのは 名前（ログインの 呼び名）と アバター と 💬 ひとこと だけ。キャラを つくっていない人は 町に 出ない。

## 4.5 🌱 Sprout Lands の 素材（2026-11-18 に ayaribon が 有料版を 買った。チョコットランドの ような 雰囲気に したい）
- 素材：**Sprout Lands - Sprites - premium pack**（作者 Cup Nooble）。元の ファイルは 非公開リポジトリ `ayaribon/making_flower_assets` に ある。**Basic pack は 商用 NG なので 使わない**（premium だけ）。
- ライセンス（premium の read_me.txt）の 要点：
  - 商用 OK・手を 加えて OK・**この 絵柄で 自分の 絵を 描くのも OK**（参考に するのも OK）
  - **NFT と AI の 学習 には 使えない**
  - **素材パック そのものを 配る・売るのは ダメ**（少し 手を 加えても ダメ）。素材を 使った 作品（ゲーム・ソフト）を 配るのは OK、**オープンソースに するのも OK**（そのときは「素材の 一部は Cup Nooble の もの」と ライセンスの 条件を 書く）
  - **クレジットが 必要**：`Assets - From: Sprout Lands - By: Cup Nooble`（アプリの `/credits` ページ・トップの いちばん下の「🙏 クレジット」・README に 書いてある）
- 使い方（`app/javascript/town_sprout.js`）：
  - 素材の 絵：地面（草・つち）・木・しげみ・花・柵・井戸・看板・ニワトリ（8まい。キーと ファイル名は `SPROUT_FILES`、サーバーは `HomesController::SPROUT_FILES`）
  - **コードで 描く オリジナル**：建物（屋根の 色は 建物ごと）・街灯・ベンチ。Sprout Lands の 色に あわせた（ライセンスで ゆるされている）
  - キャラ（アバター・Dettyan）の ふちは、Sprout Lands の 町では 黒ではなく やわらかい 赤むらさき
  - 町の 大きさ・建物の 場所・歩ける ところ は 前と 同じ（256×120）。ふんすい の 場所に 井戸
  - 画像が そろっていない（読めない）ときは、前の コードで 描く 町に もどる
- **画像の 置き場所：S3**（2026-11-18 に ayaribon が 決めた。公開リポジトリには 入れない）。`app/models/game_asset.rb`
  - 本番：ActiveStorage と 同じ バケット（Heroku の `S3_BUCKET`）の **`game_assets/sprout_lands/`**（と 人の テンプレートは `game_assets/sprout_sorry/`。Sorry pack は 非商用ライセンス。この アプリは 非商用 と ayaribon が 判断）の 下に、**素材パックの 中の 形のまま** 置く（`Animals/` `Characters/` `Objects/` `Tilesets/` `read_me.txt` が ある フォルダの 中身。例：`game_assets/sprout_lands/Objects/Water well.png`）
  - 手元：`private_assets/sprout_lands/` の 下に 同じ 形で 置く（.gitignore 済み）。元の ファイルは 非公開リポジトリ `ayaribon/making_flower_assets`
  - **開発でも S3 から 読める**：手元に ファイルが なく、`.env` に 本番と 同じ `AWS_ACCESS_KEY_ID`・`AWS_SECRET_ACCESS_KEY`・`AWS_REGION`・`S3_BUCKET` が あれば、storage.yml の `amazon` で S3 を 読む（`docker compose` の web は .env から わたす。`bin/rails server` で 動かすときは `set -a; source .env; set +a` してから）。手元に ファイルが あれば そちらが 先
  - 画面へは `GET /game_assets/sprout/:key`（ログインした人だけ。`GameAssetsController`）。知らない キー・ない 画像は 404。ブラウザには「この人だけ・1日」キャッシュ
  - 8まい ぜんぶ そろっているか は 10分ごとに 確かめる（`GameAsset::CHECK_EVERY`）。**S3 に 上げてから 町が 変わるまで、長くて 10分**（すぐ 見たいときは アプリを 再起動）
  - 読んだ 画像は サーバーが おぼえておく（ぜんぶで 30KB くらい）。DB は 使わない（N2）
