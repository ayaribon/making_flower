# 🏘️ はじまりのまち（トップページの世界）と 👤 アバター 要件

ログインしたあとのトップページを、カードのメニューから **自分のアバターで歩く「町」** にする。建物に入ると、歌ってみた・サムネ・Dettyan・切り抜き の画面へ。2026-11-18 に ayaribon が「一旦 実装してみて」（サマーウォーズの OZ のような世界、ただし見た目は このアプリの ドット絵）。

## 1. まち（`/`）
- 町の名前は **はじまりのまち**（Dettyan 育成ゲームの おはなし と同じ町）。160×120 ドットの絵（`app/javascript/town_world.js`）。
- 建物は4つ。タップすると、自分のアバターが 入口まで歩いて 入る（入ると、下のカードを押したのと同じ動き＝SiVA の画像を出して移動）。

| 建物 | 行き先 |
|---|---|
| 🎤 スタジオ | 歌ってみた（`/singing`） |
| 🎨 アトリエ | サムネ・背景（`/editor`） |
| 🏢 Dettyan の 事務所 | Dettyan 育成ゲーム（`/dettyan`） |
| ✂️ 編集室 | 切り抜き依頼（`/clip_requests/new`） |

- 地面をタップすると、そこへ歩く（ふんすいの中には入らない）。
- **ほかのメンバーのアバター**：さいきん キャラを つくった・かえた人（8人まで）が うろうろ歩く。タップすると 名前と あいさつ。リアルタイムの 同時接続では ない（ページを開いたときの 一覧）。
- **Dettyan** が 事務所の前の ひろば に立っている。タップすると「ようこそ、はじまりのまち へ！」（本人のアカウントなら「俺やん！」）。
- 空は 日本の時間で 朝・昼・夕方・夜（夜は まどと 街灯に あかり）。ふんすいの 水しぶき・くも が動く。
- まだ キャラを つくっていない人には「まずは じぶんの キャラを つくろう！」（あとで も えらべる）。
- **📋 かんたんメニュー**：前のカードのメニューも 町の下に のこす（急いでいるとき・画面読み上げ用）。カードには `data-town-place`（建物の id）を付けて、町から押す。
- 動きを減らす設定の人には、ほかの人は うろうろしない。

## 2. キャラメイク（`/avatar`）
- 町の上の「👤 キャラを つくる／かえる」から。左に 大きく 見本（まばたき・ときどき 足ぶみ）、右で えらぶ。🎲 おまかせ・↩ もとにもどす・💾 これにする（保存して 町へ もどる）。
- 体は Dettyan と同じ 20×24 ドット。えらべるもの（表は `app/javascript/avatar_sprite.js`。1つ足せば ふえる。id は保存されるので あとから変えない）：

| えらぶもの | 中身 |
|---|---|
| はだ | 5色 |
| かみがた | ショート・おだんご・ボブ・ロング・ツインテール・ポニーテール |
| かみの いろ | 9色 |
| め | ふつう・にっこり・キラキラ・きりっ |
| ふく | ジャケット・Tシャツ・パーカー ＋ 11色 |
| した | ズボン・スカート ＋ 11色 |
| くつ | 11色 |
| こもの | なし・キャップ・ヘッドホン・おおきなリボン・ねこみみ・うさみみ・はなかんむり・おうかん（Dettyan 育成ゲームの あたま の そうび の絵を つかう） |

## 3. 保存（DB）
- `users` テーブルに **`avatar` の列を 1つ** 足した（text。中身は JSON。`User` の `serialize`）。**テーブルは 増やしていない**。
  - AGENTS.md の N2（DB を増やさない。必要なら Issue で相談）に かかる。**マージの前に ayaribon が OK するか 決める**（まだ）。
  - マイグレーション：`db/migrate/20261120090000_add_avatar_to_users.rb`（本番は Procfile で デプロイのときに 自動で流れる）。
- `PATCH /avatar`（JSON：`{ avatar: { hair: "bob", ... } }`）。サーバーは 知らない項目・へんな値（数は 0〜99、文字は 英小文字だけ）を すてる（`User.clean_avatar`）。何も のこらなければ 保存しない。
- 画面は どんな データでも `normalizeAvatar` で いつも 使える形に そろえて 描く。

## 4. 守ること
- N1：音・動画は あつかわない。
- N3：PC とスマホ。建物は ボタン（キーボード・画面読み上げでも 押せる）。カードのメニューも のこす。
- N4：編集画面・歌ってみた の 中は さわらない（入口が かわるだけ）。
- ほかの人に 見えるのは 名前（ログインの 呼び名）と アバター だけ。

## 5. これから（まだ）
- ほかの画面でも 自分のアバターを使う（歌ってみた の 歌う子・切り抜き依頼の「作業中」の子・Dettyan 育成ゲームの 町の人 など）。
- リアルタイムに ほかの人が 動く（いまは 開いたときの 一覧だけ）。
- 町の見た目を フリー素材で 細かくする。
