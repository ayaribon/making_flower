# 💇 髪型パーツの 描き方（人の アバター用）

町を 歩く 人の アバター（`app/javascript/avatar_human.js`）に 差しこむ 髪型の 画像の きまり。
ほかの セッション・絵描きさん に 頼むときは、この ページを そのまま わたす。

## もとに する テンプレート
- `private_assets/sprout_sorry/Tests/free_character_spritesheet_by-cupnooble.png`（素材リポジトリ `ayaribon/making_flower_assets` の `Sprout Sorry pack/.../Tests/` に ある）
- 1コマ **16×32 ドット**。横 **8列** × たて **3だん**（全体 128×96）
- 列（向き）：0 うしろ・1 右うしろ・2 右・3 右まえ・4 まえ・5 左まえ・6 左・7 左うしろ
- だん：0 あるく・1 たつ・2 あるく（歩くと 頭が 少し 上下 する）

## 1つの 髪型に つき 2まい
| ファイル | 中身 |
|---|---|
| `<髪型>_back.png` | 体の **うしろ** に 来る 部分（後ろ髪・しっぽ・ツインテールの 束 など） |
| `<髪型>_front.png` | 体の **まえ** に 来る 部分（前髪・顔の 横の 髪・おだんご など） |

- どちらも **テンプレートと 同じ 128×96、同じ 並び**。テンプレートの 上に 重ねたとき、頭に ぴったり 合う 位置に 描く。
- **髪だけ**（顔・体・服は 描かない）。背景は 透明。
- **等倍の PNG**（拡大しない・ぼかさない・JPEG や WebP に しない）。1ドット ＝ 1ピクセル。
- 向きごとに ちゃんと 描く（うしろ向きは 後頭部、横向きは 横顔の 髪）。8方向 × 3だん、24コマ ぜんぶ。

## 色は 4色 だけ
あとで その人の 髪の 色に おきかえる ので、この 4色 だけを 使う（ほかの 色・半とうめい は 使わない）。
| 役わり | 色 |
|---|---|
| ふち | `#42353a` |
| かげ | `#695154` |
| ふつう | `#97756f` |
| ひかり | `#be9d89` |

（2026-11-18 に もらった 8種類と 同じ 色。むすびめの リボン など 髪 いがいの 色は `#f28aa8` だけ 使って よい）

## 置き場所
- 手元：`private_assets/sprout_hair/<髪型>_back.png` と `_front.png`（git には 入れない）
- 本番：S3 の `game_assets/sprout_hair/` に 同じ 名前で
- ファイル名と キャラの 髪型 の 対応（`avatar_human.js` の `HAIR_PARTS`）：bob→`short_bob`・blunt→`blunt_bob`・long→`long_straight`・twin→`twin_tails`・pony→`ponytail`・braid→`braids`（おだんご は やめた。2026-11-18）・wolf→`wolf_cut`（short は テンプレートの まま）
- **まえ用は 顔を あける**（テンプレートの 肌の ところ）。テンプレートの もとの 髪は アプリが 消して から 重ねる

## 確かめ方
テンプレートの 上に 2まいを 重ねて（back → テンプレート → front の じゅん）、24コマ ぜんぶで 頭から ずれて いないか・すきまが ないか を 見る。
