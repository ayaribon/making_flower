# 🎨 ドット絵の きまり

このアプリで ドット絵（町・アバター・Dettyan・モンスター など）を 描くときに 読む。人も AI も 同じ。
2026-11-18 に ayaribon が「ドット絵の 極意を 学習しといて」と 記事と 見本を くれたので、要点を まとめた。

- 記事：ENSAPIA Tokyo「ドット絵制作で大事なことは『こだわりをつよく持つ』こと」（2023-02-18。チョコットランドの ドットデザイナーへの インタビュー）https://ensapia-tokyo.com/recruit/story/design/id=19178/
- 下の 1 は 記事の 内容を 自分の ことばで まとめた もの（引用 では ない）。2 は 送ってもらった 見本の 絵（チョコットランドの キャラ）から 読みとった こと。3 は この アプリの きまり。
- 見本の 絵 そのものを まねて 描く（写す）のは しない。絵柄の 考え方 だけ 参考に する。

## 1. 記事から 学んだ こと
1. **斜め上から 見た 絵（クォータービュー）は 立体として 考える。** 前むき・うしろむき で 形や 間かくが ずれないように する。ここに いちばん デッサン力が 要る。
2. **1ドットで 印象が かわる。** 1ドット ずれる だけで 顔つきが かわる。仕上げは 等倍 と、少し はなれて（小さくして）見て 確かめる。
3. **描きこみ すぎない。** 細かさ と デフォルメ（かわいく くずす こと）の つりあいが 大事。細かく しすぎると かわいさが 消える。
4. **えらんで のこす（取捨選択）。** 小さく するとき、その デザインらしさを つくる ところ だけ のこす。けずった ところは 見る人の 想像が おぎなって くれる。
5. **動きで 生きている 感じを 出す。**
   - 髪・服・そうびの ゆれ。軽い もの（ピアス など）は **一拍 おくれて** ゆれる。
   - 動きに あわせた エフェクト（火花・きらきら）。
   - 動いて いる とちゅうで **表情を かえる**（ニヤッ → パッと かわいい顔）。
   - ふだん 見えない ものが ポーズで ちらっと 見える（腕を 上げると 小さい 手が 見える）。
6. **アニメは 全コマを 1まいの 画像に ならべる。**（チョコットランドの そうびは 35コマで 1セット）
7. **本物を 見て 参考に する。**（火花は 線香花火の 動画を 見た）
8. **リアルすぎず、ゲームらしい 誇張を。** 生きている 感じは のこしつつ、コミカルさ・大げささ を 強める。
9. **たのまれた ことだけ でなく、世界観の ために 足した ほうが いい ものを 提案する。**

## 2. 見本の 絵から 読みとった 絵柄（チョコットランド風）
- **向き**：斜め上から 見た 右下むき（前）と 左上むき（うしろ）を 描く。左右は 反転で つくる。
- **頭身**：2〜2.5頭身。頭と 目が 大きい。
- **目**：白い ハイライト ＋ 色の ついた 瞳（青・ピンク など）。ほっぺに ピンク。
- **ふち**：黒では なく、その 色を こくした 色。光は 左上から。
- **髪**：つや（明るい 色の 線）と、毛先の ふくらみ。
- **足もと**：うすい だ円の 影。
- **こもの**：多くても、シルエットで 何か わかる ように する。

## 2.5 見本の アニメから 読みとった こと（コマを 1まいずつ 分けて 見た）
- **コマの 長さを そろえない。** ためる ポーズ・さいごの ポーズ は 長く、動いて いる とちゅうは 短く。
  - 例：ボスの こうげき 6コマ ＝ 300・120・200・120・120・200 ミリ秒（さいしょの ためが いちばん 長い）。
  - 例：ペットの こうげき 12コマ ＝ 80〜120 で ジャンプ、60〜80 で 着地と 火花、**さいごの 1コマは 500**（決めポーズで 止まる）。
  - 例：ペットの まち（待機）23コマ ＝ ふだんは 180 で ゆっくり、はねる ところ だけ 50〜150 で 速く。
- **ため → 動き → のこり（おくれて ついてくる）→ 止め** の じゅん。
  - ため：少し しずむ・目を つぶる・うでを ひく。
  - のこり：耳・しっぽ・髪・ピアスは 体より 1〜2コマ おくれて ゆれる。着地で 少し つぶれる。
- **エフェクトは 小さく たくさん。** 1ドットの 十字の きらきら や 短い 線を、ぱっと 広げて すぐ 消す。キャラの 色に あわせる（金の たまなら 金の 火花）。
- **表情を コマで かえる。** こうげきの とちゅうで ニヤッ → にっこり。目を つぶる コマを 入れるだけでも 生き生き する。
- **足もとの だ円の 影は 動かさない**（ジャンプしても 影は 地面に のこす）。地面に 立って いる 感じが 出る。

## 2.6 参考の 絵 その2（2026-11-18 に ayaribon が「学習して いい」と くれた ピンクの 女の子の 絵）から
- **色を しぼる**：髪・服・小物 を 同じ 色の なかま（ピンク〜赤むらさき）で そろえると、まとまって かわいい。
- **線も 色つき**：ふちは 黒ではなく、いちばん こい 赤むらさき。肌の ふちは もっと うすい 色。
- **目**：上が こい（ほぼ 黒）→ 下に むかって 明るい 瞳。ひかりは 大きい 白 1つ ＋ 小さい 1つ。上まつげは 太く 外に はねる。
- **口**：あけた 口（ピンク）で 元気な 表情に なる。
- **髪**：毛の たば ごとに こい 色の 線を 入れる。毛先は ふわっと 広げて、体より 外に 出す。
- **まわりの きらきら**：十字の きらきら・花・花びら を まわりに 散らすと 画面が 華やぐ（キャラと 同じ 色の なかま）。
- **ポーズ**：片足を 上げる・手を ふる など、ななめに 動きの ある ポーズで 元気さが 出る。

## 3. この アプリの きまり（いま）
- **細かさ**：町（Sprout Lands。タイル 16×16、町 256×120）と 同じ 1ドットの 大きさで 描く（2026-11-18 に ayaribon が「町と 同じくらいの 細かさ」）。キャラは 16×20（2頭身。`avatar_chibi.js` の `drawChibi`）／16×26（シュッとした 見本。`drawSlim`）。
- **色**：Sprout Lands の パレットに よせた パステル（`avatar_chibi.js` の 色の 表）。まっくろ・まっしろ は 目と ハイライト だけ。
- **ふち**：外がわは となりの 色を こい 赤むらさき（`#4e3448`）に よせた 色（自動で つく）。黒い 線は 使わない。
- **かげ**：右と 下の はし を 少し こく（光は 左上から）。
- **左右対称**：はば 16 なら x と 15−x が 対称。目・ほっぺ・耳 は 対称に なって いるか 確かめる。
- **時間で きまる**：絵は 時間 t だけで きまる ように。乱数は 種を 固定（AGENTS.md の 5）。
- **確かめ方**：等倍 と 拡大の 両方で スクショを 見る。1人 だけで なく、町に ならべて 見る。
- **素材の ライセンス**：Sprout Lands（Sprites・UI の premium）は 商用 OK・改変 OK・**素材パック そのものの 配布は ダメ**・**NFT と AI の 学習は ダメ**・クレジット 必須。Basic pack と Sorry pack は **非商用だけ OK**。この アプリは 非商用 と ayaribon が 判断した（2026-11-18）ので、Sorry pack の 人の テンプレートを 使う。くわしくは `docs/town/requirements.md` の 4.5。

## 4. まだ やって いない こと（これから）
- クォータービュー（斜め むき）の キャラ（前・うしろ の 2方向 × 左右反転）
- 目を 大きく・色の ついた 瞳
- 髪・こもの の ゆれ（一拍 おくれ）、動作中の 表情の 変化
