# 🧑‍💼 Dettyan 育成ゲーム 要件

事務所のオーナー Dettyan（黒髪のマンバン・茶色のジャケット）を育てる、事務所の内輪向けのおまけゲーム。画面は `/dettyan`。

## 1. 遊び方の基本
- **毎日少しずつ遊ぶ**（放置あり）。ゴール・エンディングはない。
- **育つもの**：Dettyan 本人（レベル・強さ）と、事務所（お部屋・家具・所属タレント）の両方。
- Dettyan は事務所の部屋の中をちょこちょこ歩き回る（足は2コマ、歩くと「ぺたぺた」）。タップすると止まってこちらを向き、おせわのメニューが出る。

## 2. ステータス
| 名前 | 内容 |
|---|---|
| げんき | **たいりょくポイント**。モンスター退治に行くと減る。ごはん・時間で回復。上限はレベルで増える（100 ＋ レベル1つにつき 5） |
| ごきげん | 高い（70〜）とモンスター退治で少し強い・かいしんが出やすい。低い（〜29）と少し弱い |
| レベル・経験値 | モンスター退治で上がる。上がると強くなり、げんき の上限も増え、むずかしい行き先に行ける |
| そうび | ぶき（こうげき）・いしょう（たいりょく）。モンスター退治で落ちる。そうびすると見た目も変わる |
| おかね | ショップ・事務所のグレードアップに使う |

## 3. お金の入り方
| 入り方 | 中身 | 量 |
|---|---|---|
| おせわ | なでる・そうじ・話しかけると、ときどきコインが落ちる | 少し（1日の上限あり） |
| モンスター退治 | 4章（げんき を使う） | 多め |
| 毎日のごほうび | その日はじめて開いたとき | ふつう |
| 歌ってみた | MV を1本書き出すと Dettyan がほめてくれる | ふつう（1日の上限あり） |
| SiVA のおしごと | 所属タレント。放置している間に少しずつ | 少しずつ |

## 4. モンスター退治
- **げんき（たいりょくポイント）を使って、その場で行って帰ってくる**（出かけて待つ時間はない。2026-11-17 に ayaribon が決定）。げんき は時間で回復する（放置の計算は5.5）。
- ⚔️ たいじ → 行き先を選ぶ → 短いバトルの**結果を再生**（タップでとばせる）→ けっか（お金・経験値・ごはん・ぶき いしょう・レベルアップ）。
- もらうものは、再生の前に計算してセーブする（再生の途中で閉じてもなくならない）。
- その場で操作するバトルは作らない。バトルは種つきの乱数で計算する（同じ種なら同じ結果）。
- モンスターは**ふつうのスライム系**（色ちがい）。行き先・スライムの表は `app/javascript/dettyan_adventure.js`。

| 行き先 | 行けるレベル | げんき | 出てくるスライム | 落ちる そうび |
|---|---|---|---|---|
| 🌳 公園 | 1 | 15 | みどり・あお | 木のぼう・ジャージ |
| 🌲 森 | 3 | 25 | あお・みどり・むらさき | ハリセン・スーツ（＋公園のもの） |
| 🪨 どうくつ | 6 | 40 | むらさき・あお・あか・キング | マイク・ステージいしょう（＋森のもの） |
| 🏔️ 山 | 10 | 60 | あか・むらさき・キング | 金のマイク・キラキラいしょう（＋どうくつのもの） |

- 強さ：たいりょく 20 ＋ レベル×6 ＋ そうび、こうげき 3 ＋ レベル×2 ＋ そうび。次のレベルまでの経験値は 10 ＋（レベル−1）×8。
- 目安：行けるようになったばかりだと 6〜9割くらい勝てる（どうくつは そうびなしだと 6割、ハリセン＋スーツで 9割）。
- まけたら、たおした分のコインと、経験値を少しもらって帰ってくる。
- ぜんぶ たおすと、ときどき ごはんを持って帰る（公園 10%〜山 40%）。

## 4.5 ぶき・いしょう
- 1ぴきでも たおすと 15% で、その行き先の そうび のうち**まだ持っていないもの**が1つ落ちる。
- 🎒 もちもの の「🗡️ そうび」で そうびする／はずす。ぶき1つ・いしょう1つ。
- 見た目：いしょうは Dettyan の服の色（ジャケット・えり・シャツ・ズボン）を入れかえる。ぶきは右手に持つ。部屋でもバトルでも同じ。
- 表は `app/javascript/dettyan_gear.js` の `GEAR`。1つ足して、行き先の `gear` に id を書けば落ちるようになる。

## 5. ショップとごはん
- ショップでお金を使ってごはんを買い、持ち物から Dettyan にあげる。
- 最初の商品は **じゅんさい**（Dettyan の好物。ほかのごはんより大きくよろこぶ）。
- ごはんは今後増える。**商品は1つのファイルの表**（名前・値段・絵・効き目・好物かどうか）に書き、1行足せば増やせる作りにする。
  - 表は `app/javascript/dettyan_foods.js` の `FOODS`。`id` はセーブに入るので、あとから変えない。
  - 好物は ごきげん に `FAVORITE_BONUS`（10）が足され、ハートがたくさん出て大きくよろこぶ。
  - 今の商品：じゅんさい（💰15・げんき+20・ごきげん+35・好物）、おにぎり（💰8・げんき+15・ごきげん+5。好物とくらべるための ふつうのごはん）。
- おなかいっぱい（げんき・ごきげん が両方 100）のときは食べない（なくならない）。

## 5.5 おせわ（2で作ったもの）
- Dettyan をタップ → 止まってこっちを向き、メニュー：🤚なでる・🧹そうじ・💬はなす・🍙ごはん（もちものが開く）。
- 数は `app/javascript/dettyan_care.js` の上にまとめてある。

| おせわ | ごきげん | コイン |
|---|---|---|
| なでる | +6 | 35% で 1〜2枚 |
| はなす | +3 | 25% で 1枚 |
| そうじ | +2 ＋ ほこり1つにつき +3 | ほこり1つにつき 1枚（必ず） |

- 同じおせわを20秒以内に続けると、ごきげん +1 だけ・コインなし（連打で稼げないように）。
- おせわのコインは **1日 30枚まで**。日付は**サーバーの時計の日本の日付**で区切る。
- **毎日のごほうび**：その日はじめて「はじめる」を押したとき 💰20。
- **放置**（`lastSeenAt` からの時間・サーバーの時計。数えるのは3日まで）：げんき +4/時間（上限に合わせて増える。上限まで）、ごきげん −1.5/時間（30より下がらない）、ほこり が3時間ごとに1つ（5つまで）。遊んでいる間も1分ごとに数える。
- 計算のテストは `node --test test/javascript/*.mjs`（ブラウザなしで動く部分。おせわ・モンスター退治・そうび）。

## 6. 音（BGM・SE）
- 音のファイルは使わず、**ブラウザの中（Web Audio）でチップチューン風に作る**（権利の心配がない）。
- BGM：事務所（のんびり・`office`）、モンスター退治の結果（少し速い・`battle`）。
- SE：歩く「ぺたぺた」、コイン、食べる、買う、よろこぶ、攻撃、レベルアップ など。
- **音が出ることを先に知らせる**：
  - メインメニューのカードに、小さく薄く `🔊 音が出ます`。
  - ゲームを開くと「タップしてはじめる」画面。下にうっすら `※音が出ます（右上の🔇で消せます）`。タップで BGM が鳴り始める（iPhone の「タップするまで音を出せない」決まりもこれで満たす）。前に🔇にした人には注意を出さず、音なしで始める。
- 右上の🔇ボタンはいつも出しておく。BGM と SE は別々にオン／オフでき、設定はセーブに入る。

## 7. セーブ（デプロイしても消えない）
- **サーバーの `dettyan_saves` テーブル**（1人1行・JSON）が正しいセーブ。アカウントにひもづくので、PC でもスマホでも同じセーブで遊べる。デプロイしても、ブラウザのデータを消しても、iPhone で7日開かなくても消えない。引っこしコードは作らない。（N2 の例外：Issue #51 で OK 済み）
- localStorage は控え（すぐ表示する・電波が弱いとき用）。名前に**ユーザーID**を入れて、アカウントごとに分ける。
- 保存は、何かしたら少し待ってまとめて送る。画面を閉じるときにも送る。PC とスマホで同時に遊んだら、あとから保存した方を使う。
- **セーブの形が変わっても古いセーブが読めること**：
  - セーブに `version` を入れる。古い形を読んだら新しい形に直す（移しかえ）。
  - ない項目には初めの値を入れて読む。
  - 読めないセーブも**消さずに**別の名前で取っておく。
  - セーブの読み書きは `app/javascript/dettyan_save.js` だけでする。ほかから localStorage や API を直接さわらない。
- 大きさの上限：64KB。

## 8. 守ること
- N1：音や動画は送らない。送るのはゲームの数字だけ。
- N3：PC（Chrome / Edge）とスマホ（iPhone Safari）で、タップだけで遊べる。
- N4：編集画面・歌ってみたに影響を出さない。歌ってみたは MV の書き出しが成功したところに記録を残す数行だけ（別 Issue）。
