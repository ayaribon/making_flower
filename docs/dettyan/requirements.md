# 🧑‍💼 Dettyan 育成ゲーム 要件

事務所のオーナー Dettyan（黒髪のマンバン・茶色のジャケット）を育てる、事務所の内輪向けのおまけゲーム。画面は `/dettyan`。

## 1. 遊び方の基本
- **毎日少しずつ遊ぶ**（放置あり）。**おはなし（章）がある RPG**（1.5。2026-11-17 に ayaribon が決定）。エンディングを作るかは まだ決めていない。
- **育つもの**：Dettyan 本人（レベル・強さ）と、事務所（お部屋・家具・所属タレント）の両方。
- Dettyan は事務所の部屋の中をちょこちょこ歩き回る（足は2コマ、歩くと「ぺたぺた」）。タップすると止まってこちらを向き、おせわのメニューが出る。
- 見ていると、ときどき **PC で編集作業**をしたり、**マイクを持って歌ったり**する（5.7）。

## 1.5 おはなし（第1章 はじまりのまち）
- **いつものように配信していたら、異世界『はじまりのまち』に とばされていた…** から はじまる。
- さいしょは **家がなくて、まちはずれの テントで 野宿**（5.6）。お金を ためて **マイホーム** を買うと、いまの へや に すめる。家具は1つずつ買って へや に おく。
- 画面の上に **いまの目標**（🎯）を出す。たっせい すると、ステージの上に おはなし（ページ。タップで つぎへ・スキップ できる）。

| 目標 | たっせい | おはなし |
|---|---|---|
| 🗺️ ぼうけん に 出て、スライムを たおそう | ぼうけん に 1回 出る | なし |
| 🏠 お金を ためて マイホーム を 買おう（💰いま/300） | マイホーム を買う | 「ついに マイホーム！」 |
| 💻 つくえ・いす・パソコン を そろえよう（いま/3） | 3つ そろう | 「配信できる！ …でも ここ 異世界やん」→ 第1章 おしまい |

- はじめて遊ぶ人：はじまりの おはなし（配信中 → 画面が ひかる → はじまりのまち → テント）を 1回 見る。
- 前から遊んでいる人：マイホーム と ぜんぶの家具を 持っている あつかい（いままでの へや のまま）。はじまりの おはなし は「いまは マイホーム に すんでいる」で おわる版を 1回 見る。第1章の目標は たっせい ずみ。
- 表とページは `app/javascript/dettyan_story.js`（`GOALS`・`SCENES`）。けしき は `dettyan_camp.js`（テント・はじまりのまち・ひかる画面）と `dettyan_room.js`。
- **第2章から（まだ）**：つづきの おはなし・ボス・エンディング は、ayaribon と相談して決める。

## 4. ぼうけん（モンスター退治）
- 画面では「🗺️ ぼうけん」と呼ぶ（2026-11-17 に ayaribon が「たいじ」から変更）。コードの名前（`openQuest`・`dettyan_adventure.js`）はそのまま。
- **げんき（たいりょくポイント）を使って、その場で行って帰ってくる**（出かけて待つ時間はない）。げんき は時間で回復する（放置の計算は5.5）。
- 🗺️ ぼうけん → 行き先を選ぶ → **バトル（手動 か 🤖オート）** → けっか（お金・経験値・ごはん・そうび・レベルアップ）。
  - 2026-11-17 に ayaribon が「手動で たたかえるように（オートも入れる）」と決定。前の「結果を再生するだけ」から変えた。
- バトルの計算は `app/javascript/dettyan_battle.js`（画面とは別。種つきの乱数なので、同じ種で同じ行動なら同じ結果）。行き先の表は `dettyan_adventure.js`。

### 4.1 バトルの流れ
- スライムが1ぴきずつ出てくる。1ターンに、Dettyan と スライムが1回ずつ動く（**すばやさ**が高いほうが先）。
- コマンド（バトル中だけ、下のボタンの代わりに出る）：

| コマンド | すること |
|---|---|
| ⚔️ こうげき | ふつうに たたく（ときどき かいしん） |
| ✨ スキル | 職業の わざ・まほう・うた（MP を使う。4.6） |
| 🛡️ ぼうぎょ | そのターン うける ダメージが 半分。MP が 2 もどる |
| 🏃 にげる | そこで帰る（たおした分は もらえる） |
| 🤖 オート | 自分で えらばず、よさそうな行動を 自動で（HP が少ないと回復・強い あいてには つよくなる わざ など）。オンかどうかは セーブに入る |
| ⏩ さいごまで | のこりを オートで いっきに おわらせて、けっか を見る |

- **たおすたびに コインと経験値を すぐ セーブ**する（とちゅうで 閉じても なくならない）。げんき は出かけたときに使う（もどらない）。
- 毎ターン MP が もどる（まほうつかい は 2、ほかは 1）。HP と MP は、ぼうけん に出るたびに まんたん。
- ぜんぶ たおすと かち。HP が 0 になると まけ（たおした分は もらえる）。
- ぜんぶ たおすと、ときどき ごはんを持って帰る（公園 10%〜山 40%）。1ぴきでも たおすと、20% で そうび が落ちる。
- レベルアップ は バトルの おわりに まとめて（とちゅうで 閉じたときは、次に はじめたとき）。

| 行き先 | 行けるレベル | げんき | スライムの数 | 強さの倍率 | 出てくるスライム | 落ちる そうび（あたま・からだ・て・せなか・あし） |
|---|---|---|---|---|---|---|
| 🌳 公園 | 1 | 15 | 2〜3 | ×0.97 | みどり・あお | キャップ・ジャージ・木のぼう・リュック・スニーカー |
| 🌲 森 | 3 | 25 | 3〜4 | ×1.37 | あお・みどり・むらさき | ヘッドホン・スーツ・ハリセン・マント・かわぐつ（＋公園のもの） |
| 🪨 どうくつ | 6 | 40 | 3〜5 | ×1.47 | むらさき・あお・あか・キング | ライトつきヘルメット・ステージいしょう・マイク・ギター・ブーツ（＋森のもの） |
| 🏔️ 山 | 10 | 60 | 3〜5 | ×1.85 | あか・むらさき・キング | おうかん・キラキラいしょう・金のマイク・てんしのはね・キラキラくつ（＋どうくつのもの） |

- 強さの倍率：同じスライムでも、おくの行き先ほど強い（HP・こうげき・まもり に かける）。スライムの もとの強さは `dettyan_battle.js` の `MONSTERS`。あか と キング は 3ターンごとに 大わざ（1.5倍・1.7倍）。

### 4.2 強さの つりあい（2026-11-17 に ayaribon が「A」で決定）
- ねらい：**行けるようになったばかり・そうびなし で 5割くらい、その行き先の そうび が そろうと 8〜9割**。レベルを上げると勝ちやすくなる。公園は Lv1 でも だいたい勝てる。
- 前は そうび が強すぎて、そろうと ほぼ負けなかった（そうびを5か所に分けたため）。そうびの数字を半分にし、まもり を「引き算」から「わりあいで へらす」にして、行き先ごとの倍率で合わせた。
- 今の勝率（オート・「おまかせ」で ふったとき。せんし／まほうつかい／うたうたい）：

| 行き先（行けるレベル） | そうびなし | その行き先の そうび 5つ |
|---|---|---|
| 🌳 公園（Lv1） | 94／62／99% | ほぼ 100% |
| 🌲 森（Lv3） | 52／45／68% | 95／83／99% |
| 🪨 どうくつ（Lv6） | 47／61／42% | 81／93／80% |
| 🏔️ 山（Lv10） | 38／62／49% | 83／97／97% |

- このつりあいは `test/javascript/dettyan_battle_test.mjs` で確かめている（数字を変えたらテストを流す）。手動で うまく えらぶと、オートより勝ちやすい。

## 4.5 そうび（体のパーツごと）
- パーツは5つ。**1つのパーツに1つずつ**そうびできる（同じパーツのものをえらぶと入れかわる）。

| パーツ | セーブの名前 | 見た目 | 主に上がるもの |
|---|---|---|---|
| 🧢 あたま | `head` | 頭にかぶる（キャップ・ヘッドホン・ヘルメット・おうかん） | たいりょく・まもり・まほう |
| 👕 からだ | `outfit` | 服の色（ジャケット・えり・シャツ・ズボン）を入れかえる | たいりょく・まもり |
| ✋ て | `weapon` | 右手に持つ | こうげき・まほう（マイク・ステッキ） |
| 🎒 せなか | `back` | 体のうしろ（リュック・マント・ギター・てんしのはね）。PC 作業中のうしろすがたでも見える | たいりょく・すばやさ |
| 👟 あし | `feet` | くつの色（ブーツは ひざから下も） | すばやさ・まもり |

- `outfit`（からだ）と `weapon`（て）は前からあるセーブの名前なので変えない。前のセーブ（ぶき・いしょう だけ）もそのまま読める（足りないパーツは「なし」）。
- 1ぴきでも たおすと 20% で、その行き先の そうび のうち**まだ持っていないもの**が1つ落ちる。
- 👕 そうび ボタン（もちもの からも行ける）で、今のすがた・強さを見ながら、パーツごとに そうびする／はずす。
- 見た目は部屋・バトル・メインメニューのアイコンで同じ（絵は `dettyan_gear.js` の `drawDressed`）。
- 表は `app/javascript/dettyan_gear.js` の `GEAR`。1つ足して、行き先の `gear` に id を書けば落ちるようになる。絵の書き方は `GEAR` の上のコメント。
- **ショップで買う かわいい いしょう**は `price`（ねだん）を書いたもの（5章）。ぼうけん では落ちない。服の形を足したいときは、からだ・あし にも `art` / `backArt`（ポケット・おび など）を重ねられる。

## 5.5 おせわ（2で作ったもの）
- Dettyan をタップ → 止まってこっちを向き、メニュー：🤚なでる・🧹そうじ・💬はなす・🍙ごはん（もちものが開く）。
- 数は `app/javascript/dettyan_care.js` の上にまとめてある。

| おせわ | ごきげん | コイン |
|---|---|---|
| なでる | +6 | 35% で 1〜2枚 |
| はなす | +3 | 25% で 1枚 |
| そうじ | +2 ＋ ほこり1つにつき +3 | ほこり1つにつき 1枚（必ず） |

## 5.7 部屋のようす（見ているだけ。セーブは変えない）
- 部屋の絵は `app/javascript/dettyan_room.js`。窓・カーテン・SiVA のポスター・時計・本だな（トロフィー・金のレコード）・つくえ（PC・デスクライト・マグカップ）・いす・観葉植物・スピーカー・歌うための まるいラグ。**持っている家具だけ 描く**（5.6）。
- **時間で変わる**（サーバーの時計の日本の時間）：窓の外が 朝・昼・夕方・夜（夜は ほし・月・町のあかり。部屋が少し暗くなって デスクライトがつく）。時計は今の時間をさす。昼は窓から光がさしこむ。
- **PC で作業**：いすに すわって（うしろすがた）カタカタ。画面に動画の編集（プレビューとタイムライン）が動く。終わると「MV の へんしゅう できた！」など。
- **歌う**：ラグの上でマイクを持って、拍に合わせて ゆれて口をぱくぱく。音符が出て、「● REC」のランプがつき、スピーカーがふるえる。歌っている間は BGM を小さくして、Dettyan の歌（ハ長調の短いフレーズ・`sing`）を鳴らす。マイクを そうびしていれば、そのマイクで歌う。
- 作業・歌は、歩き終わって止まったとき 40% で始める（前にしてから14秒たつまでは しない）。タップ・ごはん・ぼうけん で すぐやめる。
- いす・スピーカー・Dettyan は、足もとの高さの順に描く（前後が自然に入れかわる）。

## 5.8 ぼうけん の けしき
- 絵は `app/javascript/dettyan_scenes.js`（行き先の id ごと）。動かないところは1回だけ描いて取っておき、動くところだけ毎コマ描く。
  - 🌳 公園：遠くの町・木・白いさく・ベンチ・街灯・花・道。くもが流れ、ちょうちょが飛ぶ。
  - 🌲 森：大きな木・光のすじ・きのこ・シダ。ほたるが光り、葉っぱが落ちる。
  - 🪨 どうくつ：つらら・水晶・たけのこいわ。たいまつの火がゆれて、水晶がきらっ、しずくが落ちる。
  - 🏔️ 山：雪の山・くもの海・もみの木・頂上のはた。雪がふり、はたがゆれる。

## 5.10 Dettyan 本人が遊ぶとき（「俺やん」）

## 6. 音（BGM・SE）
- 音のファイルは使わず、**ブラウザの中（Web Audio）でチップチューン風に作る**（権利の心配がない）。
- BGM：事務所（のんびり・`office`）、モンスター退治の結果（少し速い・`battle`）。
- SE：歩く「ぺたぺた」、コイン、食べる、買う、よろこぶ、攻撃、レベルアップ、PC のキーボード（小さく）、歌う など。
- **音が出ることを先に知らせる**：
  - メインメニューのカードに、小さく薄く `🔊 音が出ます`。
  - ゲームを開くと「タップしてはじめる」画面。下にうっすら `※音が出ます（右上の🔇で消せます）`。タップで BGM が鳴り始める（iPhone の「タップするまで音を出せない」決まりもこれで満たす）。前に🔇にした人には注意を出さず、音なしで始める。
- 右上の🔇ボタンはいつも出しておく。BGM と SE は別々にオン／オフでき、設定はセーブに入る。

## 7. セーブ（デプロイしても消えない）
- **サーバーの `dettyan_saves` テーブル**（1人1行・JSON）が正しいセーブ。アカウントにひもづくので、PC でもスマホでも同じセーブで遊べる。デプロイしても、ブラウザのデータを消しても、iPhone で7日開かなくても消えない。引っこしコードは作らない。（N2 の例外：Issue #51 で OK 済み）
- localStorage は控え（すぐ表示する・電波が弱いとき用）。名前に**ユーザーID**を入れて、アカウントごとに分ける。
- 保存は、何かしたら少し待ってまとめて送る。画面を閉じるときにも送る。PC とスマホで同時に遊んだら、あとから保存した方を使う。
- **セーブの形が変わっても古いセーブが読めること**：
  - セーブに `version` を入れる。古い形を読んだら新しい形に直す（移しかえ）。
  - ない項目には初めの値を入れて読む。
  - 読めないセーブも**消さずに**別の名前で取っておく。
  - セーブの読み書きは `app/javascript/dettyan_save.js` だけでする。ほかから localStorage や API を直接さわらない。
- 大きさの上限：64KB。
- いまの version は 3（1→2：ステータスの ポイント、2→3：すまい `home`・おはなし `story`。前から遊んでいる人は マイホーム と ぜんぶの家具を持つ）。
