# 🧑‍💼 Dettyan 育成ゲーム 要件

事務所のオーナー Dettyan（黒髪のマンバン・茶色のジャケット）を育てる、事務所の内輪向けのおまけゲーム。画面は `/dettyan`。

## 1. 遊び方の基本
- **毎日少しずつ遊ぶ**（放置あり）。**おはなし（章）がある RPG**（1.5。2026-11-17 に ayaribon が決定）。エンディングを作るかは まだ決めていない。
- **育つもの**：Dettyan 本人（レベル・強さ）と、事務所（お部屋・家具・所属タレント）の両方。
- Dettyan は事務所の部屋の中をちょこちょこ歩き回る（足は2コマ、歩くと「ぺたぺた」）。タップすると止まってこちらを向き、おせわのメニューが出る。
- 見ていると、ときどき **PC で編集作業**をしたり、**マイクを持って歌ったり**する（5.7）。

- 画面の大きさ：スマホは はば いっぱい。**PC は 画面の 高さに あわせて 大きく**（ステージ 4:3。はば 640〜1100px。2026-11-18 に ayaribon が「もう少し 広く」）。

## 1.5 おはなし（第1章 はじまりのまち）
- **いつものように配信していたら、異世界『はじまりのまち』に とばされていた…** から はじまる。
- さいしょは **家がなくて、まちはずれの テントで 野宿**（5.6）。お金を ためて **マイホーム** を買うと、いまの へや に すめる。家具は1つずつ買って へや に おく。
- 画面の上に **いまの目標**（🎯）を出す。たっせい すると、ステージの上に おはなし（ページ。タップで つぎへ・スキップ できる）。

| 目標 | たっせい | おはなし |
|---|---|---|
| 🗺️ ぼうけん に 出て、スライムを たおそう | ぼうけん に 1回 出る | なし |
| 🏠 お金を ためて マイホーム を 買おう（💰いま/3000） | マイホーム を買う | 「ついに マイホーム！」 |
| 💻 つくえ・いす・パソコン を そろえよう（いま/3） | 3つ そろう | 「配信できる！ …でも ここ 異世界やん」→ 第1章 おしまい |

- はじまりの おはなし（配信中 → 画面が ひかる → はじまりのまち → テント）を 1回 見る。
- **前から遊んでいる人も テントで 野宿から**（2026-11-17 に ayaribon が決定。マイホーム も 家具 も 自分で買う）。レベル・お金・そうび・ステータス は そのまま。
  - 最初の版（PR #58）では、前から遊んでいる人に マイホーム と ぜんぶの家具を わたしていた。セーブの version 4 で テントに もどし、はじまりの おはなし も もう一度 見る（自分で買った人は そのまま）。
- 目標 とは 別に、Lv5 に なると ジョブチェンジ の おはなし が出る（4.6）。
- 表とページは `app/javascript/dettyan_story.js`（`GOALS`・`SCENES`）。けしき は `dettyan_camp.js`（テント・はじまりのまち・ひかる画面）と `dettyan_room.js`。
- **第2章から（まだ）**：つづきの おはなし・ボス・エンディング は、ayaribon と相談して決める。

## 4. ぼうけん（モンスター退治）
- 画面では「🗺️ ぼうけん」と呼ぶ（2026-11-17 に ayaribon が「たいじ」から変更）。コードの名前（`openQuest`・`dettyan_adventure.js`）はそのまま。
- **げんき（たいりょくポイント）を使って、その場で行って帰ってくる**（出かけて待つ時間はない）。げんき は時間で回復する（放置の計算は5.5）。
- 🗺️ ぼうけん → 行き先を選ぶ → **たんけん（歩く → ❗なにかを みつけた！ → 📦宝箱／スライム／🤝友達）を くりかえす** → けっか（お金・経験値・ごはん・そうび・レベルアップ）。スライムとは バトル（手動 か 🤖オート）。
  - 2026-11-18 に ayaribon が「歩いて → なにかを みつけた！ → 宝箱／敵／友達 に会う」形に したいと 決定（4.0）。
  - 2026-11-17 に ayaribon が「手動で たたかえるように（オートも入れる）」と決定。前の「結果を再生するだけ」から変えた。
- バトルの計算は `app/javascript/dettyan_battle.js`（画面とは別。種つきの乱数なので、同じ種で同じ行動なら同じ結果）。行き先の表は `dettyan_adventure.js`。

### 4.0 たんけん（歩く → みつけた！ → 宝箱・スライム・友達）
- 行き先に ついたら、**歩く**（けしきが 左へ ながれて、ぺたぺた）→ Dettyan の頭に ❗「なにかを みつけた！」→ 出会う、を くりかえす。
- 出会う じゅんばん（`b.steps`）は 出かけたときに きまる（種つきの乱数。同じ種なら 同じ たんけん）。スライムの数は 前と同じ（下の表）。そこに 宝箱 と 友達 が まざる。
- **さいごまで 行くと かち**（スライムを ぜんぶ たおしている）。とちゅうで にげる・まける と そこで帰る。
- 📦 **宝箱**：お金（行き先ごと）・ごはん（25%）・そうび（15%。その行き先で 落ちるもので、まだ持っていないもの）の どれか。
- 🤝 **友達**（1回の ぼうけん で 30% で 1人）：

| 友達 | してくれること |
|---|---|
| 🐱 のらねこ | すりすり… HP が 3わり もどる |
| 🧒 まちの こども | おうえん で MP まんたん |
| 🧳 たびの しょうにん | ごはんを 1つ くれる |

- 宝箱・友達で もらったものも、**もらったら すぐ セーブ**（とちゅうで 閉じても なくならない）。けっか の画面に 宝箱・友達の数と、みつけた ごはん・そうび を出す。
- 友達の ドット絵（12×12）と 表は `dettyan_battle.js` の `FRIENDS`、宝箱の絵は `dettyan_game_controller.js` の `CHEST_SPRITE`。

### 4.1 バトルの流れ
- スライムに 出会ったら バトル。1ターンに、Dettyan と スライムが1回ずつ動く（**すばやさ**が高いほうが先）。
- コマンド（バトル中だけ、下のボタンの代わりに出る）：

| コマンド | すること |
|---|---|
| ⚔️ こうげき | ふつうに たたく（ときどき かいしん） |
| ✨ スキル | 職業の わざ・まほう・うた（MP を使う。4.6） |
| 🛡️ ぼうぎょ | そのターン うける ダメージが 半分。MP が 2 もどる |
| 🏃 にげる | そこで帰る（たおした分は もらえる） |
| 🤖 オート | 自分で えらばず、よさそうな行動を 自動で（HP が少ないと回復・強い あいてには つよくなる わざ など）。たんけん も 自動で すすむ。オンかどうかは セーブに入る（オンのときは ✋じぶんで で もどす） |
| ⏭ スキップ | のこりの たんけん と バトル を オートで いっきに おわらせて、けっか を見る |
| ⏩ はやおくり | ×1 → ×2 → ×3 → ×1。たんけん・バトルの うごき が はやくなる（中身は かわらない）。セーブに入る（`settings.battleSpeed`） |

- コマンドは2だん：上が こうげき・スキル・ぼうぎょ・にげる、下が 🤖オート・⏭スキップ・⏩はやおくり（2026-11-18 に ayaribon が決定。前は「オート」「オートで さいごまで」）。

- **たおすたびに コインと経験値を すぐ セーブ**する（とちゅうで 閉じても なくならない）。げんき は出かけたときに使う（もどらない）。
- 毎ターン MP が 1 もどる。HP と MP は、ぼうけん に出るたびに まんたん。
- **HP は たいりょく × 100**。ダメージ・回復・スライムの HP も 同じ大きさ（数百〜数千）で 見せる（計算は `HP_PER_VIT`。100 を かえても 強さの つりあい は かわらない）。
- ぜんぶ たおすと かち。HP が 0 になると まけ（たおした分は もらえる）。
- ぜんぶ たおすと、ときどき ごはんを持って帰る（公園 10%〜山 40%）。1ぴきでも たおすと、20% で そうび が落ちる。
- レベルアップ は バトルの おわりに まとめて（とちゅうで 閉じたときは、次に はじめたとき）。

| 行き先 | 行けるレベル | げんき | スライムの数 | 宝箱の数（💰） | 強さの倍率 | 出てくるスライム | 落ちる そうび（あたま・からだ・て・せなか・あし） |
|---|---|---|---|---|---|---|---|
| 🌳 公園 | 1 | 15 | 2〜3 | 0〜1（30〜60） | ×0.97 | みどり・カラス・あお | キャップ・ジャージ・木のぼう・リュック・スニーカー |
| 🌲 森 | 3 | 25 | 3〜4 | 0〜2（60〜110） | ×1.25 | あお・おばけキノコ・おおばち・みどり・むらさき | ヘッドホン・スーツ・ハリセン・マント・かわぐつ（＋公園のもの） |
| 🪨 どうくつ | 6 | 40 | 3〜5 | 1〜2（100〜180） | ×1.47 | むらさき・コウモリ・いわゴーレム・あお・あか・キング | ライトつきヘルメット・ステージいしょう・マイク・ギター・ブーツ（＋森のもの） |
| 🏔️ 山 | 10 | 60 | 3〜5 | 1〜2（160〜260） | ×1.85 | あか・ゆきおとこ・ちびドラゴン・むらさき・キング | おうかん・キラキラいしょう・金のマイク・てんしのはね・キラキラくつ（＋どうくつのもの） |

- スライム1ぴきの お金：みどり 20・あお 40・むらさき 60・あか 90・キング 180（2026-11-18 に 10倍。3.1）。
- **スライム いがいの モンスター**（2026-11-18 に ayaribon の「モンスターの種類を もっと豊富に」で 7しゅるい 足した）。表の 左ほど よく出る。

### 4.2 強さの つりあい（2026-11-17 に ayaribon が「A」で決定）
- ねらい：**行けるようになったばかり・そうびなし で 5割くらい、その行き先の そうび が そろうと 8〜9割**。レベルを上げると勝ちやすくなる。公園は Lv1 でも だいたい勝てる。
- 前は そうび が強すぎて、そろうと ほぼ負けなかった（そうびを5か所に分けたため）。そうびの数字を半分にし、まもり を「引き算」から「わりあいで へらす」にして、行き先ごとの倍率で合わせた。
- 今の勝率（オート・「おまかせ」で ふったとき。Lv5 より前は みならい、Lv5 から せんし／まほうつかい／うたうたい）：

| 行き先（行けるレベル） | そうびなし | その行き先の そうび 5つ |
|---|---|---|
| 🌳 公園（Lv1。みならい） | 91% | 100% |
| 🌲 森（Lv3。みんな みならい） | 46% | 95% |
| 🪨 どうくつ（Lv6） | 51／66／47% | 89／95／86% |
| 🏔️ 山（Lv10） | 42／65／58% | 92／99／99% |

- 2026-11-18 の たんけん（4.0）で、友達の 回復・MP の ぶん 少し 上がった（数ポイント）。スライムの 強さは かえていない。
- このつりあいは `test/javascript/dettyan_battle_test.mjs` で確かめている（数字を変えたらテストを流す）。手動で うまく えらぶと、オートより勝ちやすい。

## 4.5 そうび（体のパーツごと）
- パーツは5つ。**1つのパーツに1つずつ**そうびできる（同じパーツのものをえらぶと入れかわる）。

| パーツ | セーブの名前 | 見た目 | 主に上がるもの |
|---|---|---|---|
| 🧢 あたま | `head` | 頭にかぶる（キャップ・ヘッドホン・ヘルメット・おうかん） | たいりょく・まもり・まほう |
| 👕 からだ | `outfit` | 服の色（ジャケット・えり・シャツ・ズボン）を入れかえる | たいりょく・まもり |
| ✋ て | `weapon` | 右手に持つ | こうげき・まほう（マイク・ステッキ） |
| 🎒 せなか | `back` | 体のうしろ（リュック・マント・ギター・てんしのはね）。PC 作業中のうしろすがたでも見える | たいりょく・すばやさ |
| 👟 あし | `feet` | くつの色（ブーツは ひざから下も） | すばやさ・まもり |

- `outfit`（からだ）と `weapon`（て）は前からあるセーブの名前なので変えない。前のセーブ（ぶき・いしょう だけ）もそのまま読める（足りないパーツは「なし」）。
- 1ぴきでも たおすと 20% で、その行き先の そうび のうち**まだ持っていないもの**が1つ落ちる。
- 👕 そうび ボタン（もちもの からも行ける）で、今のすがた・強さを見ながら、パーツごとに そうびする／はずす。
- 見た目は部屋・バトル・メインメニューのアイコンで同じ（絵は `dettyan_gear.js` の `drawDressed`）。
- 表は `app/javascript/dettyan_gear.js` の `GEAR`。1つ足して、行き先の `gear` に id を書けば落ちるようになる。絵の書き方は `GEAR` の上のコメント。
- **ショップで買う かわいい いしょう**は `price`（ねだん）を書いたもの（5章）。ぼうけん では落ちない。服の形を足したいときは、からだ・あし にも `art` / `backArt`（ポケット・おび など）を重ねられる。

## 4.6 ステータス・職業・スキル（📊 つよさ）
- 下のボタン「📊 つよさ」で開く。まだ ふっていない ポイントがあると、ボタンに 数字の しるし。
- **ステータス**は5つ：

| ステータス | 1ポイントで | きくところ |
|---|---|---|
| たいりょく | +1（HP +100） | HP ＝ たいりょく × 100。0 になると まけ |
| こうげき | +1 | ふつうの こうげき・せんし の わざ |
| まもり | +1 | うける ダメージが へる（わりあい。まほう には 3/4 だけ きく） |
| まほう | +1 | まほう・うた・回復。MP も ふえる（MP ＝ 5 ＋ レベル ＋ まほう） |
| すばやさ | +1 | 先に動ける・かいしん が出やすい |

- **レベルが1つ上がるごとに 3ポイント**。＋／− で ふる。どの パラメータ も 1ポイントで +1（2026-11-17 に ayaribon が決定。前は たいりょく だけ +4 だった）。じっさいの HP は たいりょく × 100。**🤖 おまかせ** は のこりを 職業に あった わりあいで ふる。**↩ ふりなおし** は いつでも ただ。
- 前から遊んでいる人には、今のレベルまでの ポイントを まとめて わたす（セーブの version 2 への移しかえ）。
- **職業**：さいしょは みんな **🔰 みならい**。**Lv5 に なると ジョブチェンジ** できる（せんし・まほうつかい・うたうたい。2026-11-17 に ayaribon が決定）。ジョブチェンジ した あとは いつでも ただで かえられる（みならい には もどれない）。
  - Lv5 に なったとき、はじまりのまち の しんでん の おはなし（3ページ）が 1回 出る。
  - 職業で「レベルで上がる強さ」と「おぼえるスキル」が かわる（ふった ポイントは そのまま。かえると、いまの レベルぶん その職業の 強さに なる）。
  - 前の版で Lv5 より下なのに 職業が ついていた人は、みならい に もどす（セーブの version 5）。

| 職業 | とくい | スキル（おぼえるレベル・MP） |
|---|---|---|
| 🔰 みならい（さいしょ） | なんでも すこしずつ | がんばりパンチ（1・3。こうげき 1.6倍）・ひとやすみ（3・4。回復） |

## 6. 音（BGM・SE）
- 音のファイルは使わず、**ブラウザの中（Web Audio）でチップチューン風に作る**（権利の心配がない）。
- BGM：事務所（のんびり・`office`）、モンスター退治の結果（少し速い・`battle`）。
- SE：歩く「ぺたぺた」、コイン、食べる、買う、よろこぶ、攻撃、レベルアップ、PC のキーボード（小さく）、歌う など。
- **音が出ることを先に知らせる**：
  - メインメニューのカードに、小さく薄く `🔊 音が出ます`。
  - ゲームを開くと「タップしてはじめる」画面。下にうっすら `※音が出ます（右上の🔇で消せます）`。タップで BGM が鳴り始める（iPhone の「タップするまで音を出せない」決まりもこれで満たす）。前に🔇にした人には注意を出さず、音なしで始める。
- 右上の🔇ボタンはいつも出しておく。BGM と SE は別々にオン／オフでき、設定はセーブに入る。

## 7. セーブ（デプロイしても消えない）
- **サーバーの `dettyan_saves` テーブル**（1人1行・JSON）が正しいセーブ。アカウントにひもづくので、PC でもスマホでも同じセーブで遊べる。デプロイしても、ブラウザのデータを消しても、iPhone で7日開かなくても消えない。引っこしコードは作らない。（N2 の例外：Issue #51 で OK 済み）
- localStorage は控え（すぐ表示する・電波が弱いとき用）。名前に**ユーザーID**を入れて、アカウントごとに分ける。
- 保存は、何かしたら少し待ってまとめて送る。画面を閉じるときにも送る。PC とスマホで同時に遊んだら、あとから保存した方を使う。
- **セーブの形が変わっても古いセーブが読めること**：
  - セーブに `version` を入れる。古い形を読んだら新しい形に直す（移しかえ）。
  - ない項目には初めの値を入れて読む。
  - 読めないセーブも**消さずに**別の名前で取っておく。
  - セーブの読み書きは `app/javascript/dettyan_save.js` だけでする。ほかから localStorage や API を直接さわらない。
- 大きさの上限：64KB。
- いまの version は 6（1→2：ステータスの ポイント、2→3：すまい `home`・おはなし `story`（みんな テントから）、3→4：前の 3 で わたしていた マイホーム と家具を テントに もどす、4→5：Lv5 より下は みならい に、5→6：お金の ねだんを 10倍に したので、持っている お金も 10倍）。

## 8. 守ること
